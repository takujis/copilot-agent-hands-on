# RFP Analysis Agent

## 概要

このハンズオンでは、Microsoft 365 Copilot の Agent Builder を使用して、RFP（提案依頼書）を分析するエージェントを作成します。

Agent Builder の基本的な操作方法に加え、Knowledge を活用した業務特化型エージェントの作成方法を学習します。

また、公開 Web の情報を参照しながら、提案候補となる製品・サービスの調査を行う方法も体験します。

### 作成するエージェント

RFP Analysis Agent

主な機能:

- RFP の要約
- 必須要件、評価基準、期限の整理
- Proposal Review Guide に基づく提案レビュー
- 提案リスクの分析
- 顧客への確認質問の生成
- Microsoft ソリューション候補の整理
- Web 検索による最新情報の参照

> [!IMPORTANT]
>
> 本手順は RFP 分析エージェントの設計や実装に関するベストプラクティスを示すものではありません。
>
> Agent Builder を利用したエージェント作成を通じて、Knowledge、Instructions、Web Search の活用方法を学習することを目的としています。
