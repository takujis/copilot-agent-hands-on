# エージェントにサポートチケット機能を実装する

この手順では、IT Support Agent にサポートチケット機能を追加します。

サポートチケット作成用のプロンプトとトピックを作成し、ユーザーが問い合わせ内容を登録できるようにします。

## お問い合わせ内容のカテゴリ分類プロンプトを作成する

1. エージェントの [ツール] タブを開き、[ツールを追加する] をクリックします。

2. 新規作成の [プロンプト] をクリックします。

3. 以下を入力して設定します。

   プロンプト名

   ```text
   Ticket Category Classification
   ```

   指示

   ```text
   お問い合わせ内容を分析し、最も適切なカテゴリを 1 つ選択してください。
   
   タイトル:
   {ticketTitle}

   詳細:
   {ticketDescription}
   
   カテゴリ:

   - PasswordReset
   - AccessRequest
   - EmailIssue
   - TeamsIssue
   - DeviceIssue
   - NetworkIssue
   - ApplicationIssue
   - SecurityIssue
   - Other
   
   カテゴリ選択ルール:
   
   - お問い合わせ内容に最も適したカテゴリを 1 つだけ選択すること。
   - 複数のカテゴリに該当する場合は、主な問題に最も近いカテゴリを選択すること。
   - カテゴリを特定できない場合は Other を選択すること。
   - 推測による分類は行わず、お問い合わせ内容から判断できる情報のみを使用すること。
   
   出力ルール:

   - 以下の形式で出力すること。
   
   {
   "category": "<カテゴリ名>"
   }
   ```

   `{ticketTitle}`、`{ticketDescription}` の文字列を削除し、それぞれの位置に、[コンテンツを追加する] から [入力] > [テキスト] をクリックして、以下を設定して追加します。
   | 名前 | サンプル データ |
   |------|------|
   | ticketTitle | Teams に組織外ユーザーを追加できない |
   | ticketDescription | Teams に組織外ユーザーを追加できません。「問題が発生しました」というエラーが発生します。 |

4. 出力を [JSON] に切り替えます。

5. [テスト] をクリックし、テスト結果に問題がなければ [保存] をクリックします。

6. [追加と構成] をクリックします。

7. 追加した [Ticket Category Classification] で、[詳細] セクションの [追加情報] を展開して [トピックまたはエージェントによって参照されている場合のみ] にチェックを入れます。

8. 続けて、[完了] セクションの [高度] を展開して [指定] を選択し、[出力を追加する] をクリックして `category` を追加します。

9. [保存] をクリックします。

## サポートチケット作成トピックを作成する

1. [トピック] タブを開き、[トピックの追加] > [最初から] をクリックします。

2. トピック名に以下を入力して設定します。

    ```text
    サポートチケット作成
    ```

3. トリガーの [トピックの機能を説明する] に以下を入力します。

    ```text
    ユーザーが IT サポートへの問い合わせ登録やサポートチケットの作成を希望した場合に起動します。
    ```

4. [+] から [アダプティブ カードで質問する] を追加し、[...] > [プロパティ] からプロパティを開き、[アダプティブ カードを編集する] > [カード ペイロード エディター] に以下を入力して保存します。

    ```text
    {
        "type": "AdaptiveCard",
        "$schema": "https://adaptivecards.io/schemas/adaptive-card.json",
        "version": "1.5",
        "body": [
            {
              "type": "TextBlock",
              "text": "お問い合わせ内容を入力してください。",
              "wrap": true
            },
            {
                "type": "Input.Text",
                "id": "title",
                "label": "タイトル",
                "isRequired": true,
                "errorMessage": "タイトルを入力してください。"
            },
            {
                "type": "Input.Text",
                "id": "details",
                "label": "詳細",
                "isRequired": true,
                "isMultiline": true,
                "errorMessage": "詳細を入力してください。"
            }
        ],
        "actions": [
            {
            "type": "Action.Submit",
            "title": "送信"
           }
        ]
    }
    ```

5. [+] から [ツールを追加する] > [ツール] タブ > [Ticket Category Classification] を追加し、入力の [値を設定する] から以下を追加して設定します。

   | 入力 | 値 |
   |------|------|
   | ticketTitle (String) | `title` (Topic.title) |
   | ticketDescription (String) | `details` (Topic.details) |

   [ticketTitle]、[ticketDescription] の値には、[...] をクリックして該当する変数を選択して設定します。

6. [+] から [ツールを追加する] > [コネクタ] タブ > [選択した環境に新しい行を追加する] (Microsoft Dataverse) を検索して追加します。

7. 既存の接続を選択するか、または [新しい接続を作成する] をクリックして接続を作成し、[送信する] をクリックします。

8. [選択した環境に新しい行を追加する] ノードの [...] > [プロパティ] からプロパティを開き、[開始]、[入力]、[出力] タブでそれぞれ以下を設定します。

   - 開始

     - [エンド ユーザー認証] には [エンド ユーザーの資格情報] を設定

   - 入力
   
     | パラメーター | 値 |
     |------|------|
     | 環境 | 現在使用している環境 |
     | テーブル名 | `Support Tickets` |
     | Title | `Title` (Topic.title) |
     | Details | `details` (Topic.details) |
     | Category | `category` (predictionOutput.structuredOutput.category) |

     [Title]、[Details]、[Category] の値には、[...] をクリックして該当する変数を選択して設定します。

   - 出力

     - 変数名を `SupportTicket` に変更します。

9. [+] から [メッセージを送信する] を追加し、以下を入力して設定します。

    ```text
    サポートチケットを作成しました。担当者より確認してご連絡いたします。
    チケット番号: {TicketNumber}​​
    ```

    `{TicketNumber}` の文字列を削除し、その位置に、[変数を挿入する] アイコンをクリックし、[カスタム] タブで「number」で検索してチケット番号に該当する変数を選択して挿入します。

10. [保存] をクリックして、トピックを保存します。

## ナレッジから回答できない場合のトピックを作成する

1. [トピックの追加] > [最初から] をクリックします。

2. トピック名に以下を入力して設定します。

   ```text
   ナレッジから回答できない場合
   ```

3. トリガーの [トピックの機能を説明する] に以下を入力します。

   ```text
   ナレッジから回答を提供できない場合に起動し、サポートチケットを作成するかどうかをユーザーに確認します。
   ```

4. [+] から [質問する] を追加し、以下を入力して設定します。

   ```text
   お問い合わせ内容に関する情報が見つかりませんでした。サポートチケットを作成して、サポート担当者に問い合わせますか？「はい」または「いいえ」でお答えください。
   ```

5. 続けて、[質問する] ノードの [特定] には [複数選択式オプション] を選択し、[ユーザーのオプション] として `はい` および `いいえ` を追加します。

6. 条件 [いいえ] の後には、[+] から [メッセージを送信する] を追加し、以下を入力して設定します。

   ```text
   他にお手伝いできることがありましたら、お知らせください。
   ```

7. [保存] をクリックして、トピックを保存します。

## サポートチケット取得のツールを追加する

1. [ツール] タブを開き、[ツールを追加する] をクリックします。

2. [ツールの追加] ダイアログで、[モデル コンテキスト プロトコル] を選択した状態で [Microsoft Dataverse MCP Server] を検索して選択します。

3. 既存の接続を選択するか、または [新しい接続を作成する] をクリックして接続を作成し、[追加と構成] をクリックします。

4. 追加した Microsoft Dataverse MCP Serverの [ツール] セクションで、ツール一覧の右上にあるトグルをオフにし、以下のツールのみをオンにします。

   - read_query
   - describe

5. [保存] をクリックします。

## エージェントをテストする

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   サポートチケットを作成したい
   ```

> [!NOTE]
>
> [Microsoft Dataverse] の接続を求められた場合は、[許可] をクリックして続行します。

2. 表示されたフォームにお問い合わせ内容を入力して送信します。

3. エージェントの応答と Support Ticket テーブルのレコードを確認します。

> [!NOTE]
>
> Power Apps Maker Portal で Support Ticket テーブルを開き、作成されたレコードを確認します。
>
> 既定では一部の列のみ表示されます。[その他の xx 件] をクリックして、表示する列を追加することができます。
