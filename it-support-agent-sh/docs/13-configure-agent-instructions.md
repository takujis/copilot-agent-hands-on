# IT Support Agent のインストラクションを設定する

この手順では、IT Support Agent の回答方針やトピックなどの利用ルールを設定します。

インストラクションを設定することで、ナレッジに基づいた回答、サポートチケットの作成、サポートチケットの状態確認を適切に実行できるようにします。

1. エージェントの [概要] タブを開き、[指示] に以下を入力し、保存します。

   ```text
   # 目的

   このエージェントは、社内 IT サポートに関する問い合わせに回答します。

   # 回答方針

   - 回答は必ず設定されたナレッジソースのみを使用すること。
   - 一般知識、事前学習済み知識、Web 上の情報、推測を用いて回答してはならない。
   - ナレッジソースに記載されていない内容を補完してはならない。
   - 回答に必要な情報がナレッジソース内に存在しない場合は、推測せず {ナレッジから回答できない場合} を実行すること。

   # サポートチケット作成

   ## 基本ルール

   - 問い合わせ内容には、ユーザーが明示的に伝えた事実のみを使用すること。
   - 推測、補完、想像を含めてはならない。
   - エージェントが提案した対処方法を、ユーザーが実施済みとして記載してはならない。
   - ユーザーが実施した内容と、エージェントが提案した内容は区別すること。
   - 会話履歴から問い合わせ内容を作成する場合も、ユーザーが明示した事実のみを要約すること。
   - サポートチケット作成前に、必ずユーザーの明確な同意を取得すること。

   ## サポートチケット作成の実行

   以下に該当する場合は {サポートチケット作成} を実行すること。

   - サポートチケットを作成したい
   - 問い合わせを登録したい
   - サポートへ依頼したい
   - チケットを起票したい
   - IT 部門へエスカレーションしたい

   ## サポートチケット作成後の応答

   サポートチケット作成後は、チケット作成に関するメッセージを追加で出力しないこと。

   # サポートチケット確認

   ユーザーがサポートチケットの確認を希望した場合は、Dataverse MCP Server ツールを使用して Support Ticket テーブルを検索すること。
   検索条件が指定されている場合は、その条件を検索条件に含めること。
   ```

   `{ナレッジから回答できない場合}` および `{サポートチケット作成}` の文字列を削除し、それぞれの位置に、[追加] をクリック (または、半角スペース + `/` を入力) して該当トピックの参照を追加します。

## エージェントをテストする

### テスト 1: サポートチケットを作成する

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   Teams に組織外ユーザーを追加できません。エラーになります。
   ```

> [!NOTE]
>
> [Microsoft Dataverse] の接続を求められた場合は、[許可] をクリックして続行します。

2. エージェントの応答を確認します。

   > 期待される動作:
   > - 問い合わせ内容に関する情報がナレッジにない旨の応答が返されること
   > - サポート チケットの作成が提案されること

   > 内部動作:
   > - ナレッジから回答できない場合トピックが実行されること

3. エージェントからのサポート チケット作成の提案に対して同意します。

   > 期待される動作:
   > - お問い合わせ内容を入力するフォームが表示されること

   > 内部動作:
   > - サポートチケット作成トピックが実行されること

4. 表示されたフォームにお問い合わせ内容を入力して送信します。

5. エージェントの応答を確認します。

   > 期待される動作:
   > - サポート チケットが作成された旨の応答が返されること
   > - チケット番号が表示されること
   
   > 内部動作:
   > - Support Ticket テーブルにレコードが作成されること

> [!NOTE]
>
> Power Apps Maker Portal で Support Ticket テーブルを開き、作成されたレコードを確認します。
>
> 既定では一部の列のみ表示されるため、[その他の xx 件] をクリックして、表示する列を追加することができます。

### テスト 2: サポートチケットを確認する

1. [+] をクリックして、新しいチャットを開始します。

2. チャット入力欄に以下のようなメッセージを入力して送信します。

   ```text
   サポートチケット <チケット番号> について教えて
   ```

3. エージェントの回答内容を確認します。

   > 期待される動作:
   > - 指定したチケット番号の情報を取得できること

   > 内部動作:
   > - Dataverse MCP Server のツールが呼び出されること
