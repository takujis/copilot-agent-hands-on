# マルチエージェントを構成する

ここまでの手順で、社内 IT に関する問い合わせに対応する IT Support Agent を作成しました。

PC やスマートフォンなどの業務デバイスの貸出や返却に関する問い合わせも想定されますが、組織によっては、これらの業務デバイスの管理を別のチームが担い、IT サポートとは異なる業務領域として扱われる場合があります。

そこで、業務デバイスに関する問い合わせを担当する専用のエージェントを作成し、IT Support Agent から利用できるようにします。

> [!IMPORTANT]
>
> Copilot Studio 試用版ライセンスではエージェントを公開できません。その場合は、公開の手順以降をスキップしてください。

## Device Assistant を作成する

1. 左側のナビゲーションから [エージェント] を選択し、エージェントを作成します。

   - 新しいエクスペリエンスの場合
     - [新しいエージェント] のドロップダウン メニューから [エージェント] (標準) をクリックします。

   - クラシック エクスペリエンスの場合
     - [空のエージェントを作成する] をクリックします。

> [!NOTE]
>
> 新しいエクスペリエンスからクラシック エクスペリエンスに切り替える場合は、ホームページで上部の **[New experience]** トグルをオフにします。
>
> クラシック エクスペリエンスから新しいエクスペリエンスに切り替える場合は、ホームページで上部の **[今すぐ試す]** をクリックします。

2. エージェントの名前と言語を設定し、[作成] をクリックします。

   | 項目 | 設定内容 |
   |------|------|
   | 名前 | Device Assistant (Standard) |
   | 言語 | 日本語 (日本) |

   [エージェント設定 (オプション)] を展開すると、言語の設定が表示されます。

3. 右上の [設定] をクリックします。

4. [生成 AI] > [オーケストレーション] で、[エージェントの応答に生成 AI オーケストレーションを使用しますか?] で [はい] が選択されていることを確認します。

5. [生成 AI] > [接続されたエージェント] で、[他のエージェントがこれに接続し、使用できるようにする] がオンになっていることを確認します。

6. [生成 AI] > [ナレッジ] で、[根拠のない応答を許可する] および [Webの情報を使用する] をオフにします。

7. 下部の [保存] をクリックして保存し、設定を閉じます。

8. エージェントの [説明] に以下を入力し、保存します。

   ```text
   業務用デバイスおよび周辺機器に関する問い合わせに回答するエージェントです。
   ```

9. [指示] に以下を入力し、保存します。

   ```text
   # 目的

   このエージェントは、業務用デバイスおよび周辺機器に関する問い合わせに回答することを目的としています。

   # 対応範囲

   以下の問い合わせに対応します。

   - デバイスの返却
   - デバイスの交換
   - デバイスの貸出
   - デバイスの紛失
   - 周辺機器の貸出

   # 回答方針

   - 回答は必ず設定されたナレッジソースに基づいて作成すること。
   - 推測や一般的な知識に基づいて回答してはいけない。
   - ナレッジソースに記載されていない内容を補完してはいけない。
   - ナレッジソースに十分な情報が存在しない場合は、その旨をユーザーに伝えること。
   - ユーザーに回答を送信する前に、回答内容がナレッジソースに記載されていることを確認すること。
   - 確認できない情報は回答してはいけない。

   # 対象外

   以下の内容は、このエージェントの対応範囲外です。

   - 人事制度
   - 福利厚生
   - 経費精算
   - ライセンス申請
   - アカウント管理
   - アプリケーション障害
   - IT サポートチケットの作成
   - その他、業務用デバイスおよび周辺機器に関係しない内容

   対応範囲外の内容については回答せず、このエージェントの対応範囲外であることをユーザーに伝えること。
   ```

10. [ナレッジ] で [ナレッジの追加] をクリックします。

11. **[Device_Support_Guide.docx](../assets/Device_Support_Guide.docx)** ファイルをアップロードし、[エージェントに追加する] をクリックします。

> [!NOTE]
>
> テストを実施する前に、ナレッジに追加した **Device_Support_Guide.docx** の状態が **準備完了** になっていることを確認してください。

## エージェントをテストする

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

    ```text
    デバイス交換のガイドラインを教えてください。
    ```

2. エージェントの回答内容を確認します。

3. Device Assistant の動作に問題がないことを確認したら、[公開] をクリックしてエージェントを公開します。

## IT Support Agent に Device Assistant を追加する

1. IT Support Agent を開きます。

2. [エージェント] タブを開き、[追加] をクリックします。

3. [Device Assistant] を選択します。

4. [説明] に以下を入力し、[追加と構成] をクリックします。

    ```text
    業務用デバイスおよび周辺機器に関する問い合わせに回答するエージェントです。
    ```

5. [指示] の「サポートチケット作成」セクションの末尾に、以下を追加します。

   ```text
   ## サポートチケット作成の例外

   デバイスの返却、交換、貸出、紛失、および周辺機器の貸出に関する内容は、サポートチケットの対象外です。

   これらの内容については Device Assistant が対応します。
   ```

6. 続けて、[指示] の最後に以下を追加し、保存します。

   ```text
   # 業務用デバイスおよび周辺機器に関する問い合わせ

   ユーザーが以下に関する問い合わせを行った場合は、自身で回答せず、{Device Assistant} エージェントを呼び出してください。

   - デバイスの返却
   - デバイスの交換
   - デバイスの貸出
   - デバイスの紛失
   - 周辺機器の貸出・追加・交換

   例:

   - PC を返却したい
   - Surface が故障した
   - モニターを追加したい
   - ヘッドセットを借りたい
   - ノート PC を交換したい
   - 業務用 PC を紛失した

   Device Assistant エージェントとメイン エージェントの応答を統合して回答する場合は、それぞれの役割や回答内容が分かるように整理して回答してください。
   異なるエージェントの回答内容を混同したり、結論を統合したりしてはいけません。​
   ```

   `{Device Assistant}` の文字列を削除し、その位置に、[追加] をクリック (または、半角スペース + `/` を入力) して該当エージェントの参照を追加します。

## エージェントをテストする

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   ノート PC を返却したいです。どうしたらいいですか。
   ```

2. エージェントの回答内容を確認します。

3. 新しいテスト セッションを開始するために、[+] をクリックします。
 
4. 次は、チャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   PC が起動しません。何か対処方法はありますか？交換できるなら交換したいです。
   ```

5. エージェントの回答内容を確認します。
