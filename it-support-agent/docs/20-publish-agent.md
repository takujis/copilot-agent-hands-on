# エージェントを公開する

作成したエージェントを公開し、Microsoft 365 Copilot から利用できるようにします。

> [!IMPORTANT]
>
> Copilot Studio 試用版ライセンスではエージェントを公開できません。その場合は、以降の手順をスキップしてください。

1. [公開] をクリックします。

2. [このエージェントを公開する] ダイアログで [公開する] をクリックし、エージェントを公開します。

3. [チャネル] タブを開き、[Microsoft のチャネル] > [Microsoft 365 と Microsoft Teams] をクリックします。

4. [エージェントを Microsoft 365 Copilot で使用可能にする] にチェックを入れた状態で [チャネルを追加する] をクリックします。

5. [Microsoft 365 で エージェント を表示する] をクリックします。

6. エージェントの追加ダイアログで [追加] をクリックします。

7. エージェントが追加されたら、エージェントに質問をして動作を確認します。

> [!NOTE]
>
> 他のユーザーが利用できるようにする場合は、エージェントのアクセス権や共有範囲の設定など、追加の設定や操作が必要です。
