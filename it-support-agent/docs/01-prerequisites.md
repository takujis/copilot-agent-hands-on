# 前提条件

本ハンズオンでは、Copilot Studio で Standard harness を利用したエージェントを作成するために、事前準備を行います。

## 必要なライセンス

本ハンズオンを実施するためには、以下が必要です。

- Power Apps 開発者プランまたは有効なライセンス
- Microsoft Copilot Studio 試用版または有効なライセンス

> [!IMPORTANT]
> Copilot Studio 試用版ライセンスではエージェントを公開できません。そのため、本ハンズオンの一部の手順を実施できません。公開に関する手順は必要に応じてスキップしてください。

## Microsoft 365 テナント

本ハンズオンを実施するには、Microsoft 365 テナントが必要です。

Microsoft 365 テナントをお持ちでない場合は、Microsoft 365 開発者プログラムや Microsoft 365 の試用版などを利用してテナントを準備します。

## Power Apps 開発者プランにサインアップする

[How can I get the Power Apps Developer Plan?](https://learn.microsoft.com/en-us/power-platform/developer/plan#how-can-i-get-the-power-apps-developer-plan) をご覧ください。

## Copilot Studio 試用版にサインアップする

[Copilot Studio試用版にサインアップする](https://learn.microsoft.com/ja-jp/microsoft-copilot-studio/requirements-licensing-subscriptions#sign-up-for-a-copilot-studio-trial) をご覧ください。
