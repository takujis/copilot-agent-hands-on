---
name: extract-travel-request-details
description: ユーザーがアップロードした出張申請書から基本情報を抽出
---
この Skill は、ユーザーがアップロードした出張申請書から、基本情報を抽出します。

抽出項目:
- 申請日
- コストセンター
- 社員番号
- 氏名
- 所属部門
- 役職
- 内線番号
- メールアドレス
- 訪問国／訪問都市
- 訪問先企業
- 出張期間
- 出張種別
- 出張目的
- 期待効果

出力形式:

抽出した基本情報は、以下の形式で表にまとめること。
表には「抽出項目」に記載された項目をすべて含めること。

| 項目 | 内容 |
|------|------|
| 申請日 | xxx |
| 社員番号 | xxx |
| 氏名 | xxx |

注意事項:
- ファイル内に記載された情報のみを抽出する。
- 情報が見つからない場合は「不明」と表示する。
- 推測で補完しない。
