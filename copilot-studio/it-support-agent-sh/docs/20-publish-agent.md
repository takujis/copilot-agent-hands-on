# 8. エージェントを公開する (Copilot Studio 共通タスク)

作成したエージェントを公開し、Microsoft 365 Copilot と Microsoft Teams で使用するための設定を行います。この手順は、Copilot Studio で作成したエージェント全般に共通です。

> **Note**
> Copilot Studio 試用版ライセンスでは、エージェントを公開することはできません。その場合は、この演習をスキップしてください。

## 8.1. 認証を確認する

1. エージェントのページの右上部にある [設定] を選択します。
2. [設定] ウィンドウの [セキュリティ] タブで [認証] をクリックします。[Microsoft で認証する] が選択されていることを確認します。
3. [設定] ウィンドウを閉じます。

## 8.2. エージェントを公開する

1. ページの上部にある [公開] をクリックします。
2. [このエージェントを公開する] ウィンドウで [公開する] をクリックし、エージェントを公開します。
3. [チャネル] ページでエージェントの状態を確認します。

## 8.3. Teams と Microsoft 365 Copilot のチャネルを追加する

1. [Microsoft のチャネル] で [Teams と Microsoft 365 Copilot] をクリックします。
2. [チャネルを追加する] をクリックします。

   > **Note**
   > この手順では、[エージェントを Microsoft 365 Copilot で使用可能にする] にチェックを入れた状態にします。

3. [詳細の編集] をクリックします。
4. エージェントのアイコン、色、説明などを必要に応じて変更し、[保存] をクリックします。

   > **Note**
   > 他のユーザーがエージェントを使用できるようにするためには、さらに追加の設定が必要です。

5. [Teams と Microsoft 365 Copilot] ウィンドウを [×] をクリックして一度閉じます。
6. ページの上部の [公開] をクリックし、[このエージェントを公開する] ウィンドウで [公開する] をクリックします。

## 8.4. Microsoft 365 Copilot でエージェントを利用する

1. 再度、[Microsoft のチャネル] > [Teams と Microsoft 365 Copilot] から [Teams と Microsoft 365 Copilot] ウィンドウを開き、[Microsoft 365 でエージェントを表示する] をクリックします。
2. [追加] をクリックし、エージェントを追加します。
3. エージェントが追加されたことを確認します。
4. 質問を入力し、応答を確認します。
