# 2. Dataverse テーブルを作成する

Power Apps を使用して、エージェントで使用するサポートチケットを管理するテーブルを作成します。

> **Note**
> この演習で使用する [SupportTicket.xlsx](../assets/SupportTicket.xlsx) をあらかじめダウンロードして、PC に保存してください。

## 2.1. 環境を選択する

1. Power Apps ホームページ <https://make.powerapps.com> にアクセスします。
2. 右上の [環境] をクリックし、[環境を選択] ウィンドウが表示されたら、使用する Power Platform 環境を選択します。
3. 右上の [環境] で該当の環境が選択されていることを確認します。

## 2.2. Excel からテーブルをインポートする

1. 左側のナビゲーションで [テーブル] を選択します。
2. テーブル セクションのトップ バーで、[+ 新しいテーブル] をクリックし、[新しいテーブルを作成する] を選択します。
3. [Excel ファイルまたは .CSV をインポート] オプションを選択して、新しいテーブルを作成します。
4. [デバイスから選択] をクリックし、ダウンロードした `SupportTicket.xlsx` を選択します。
5. [Excel または .CSV ファイルをインポート] で [インポート] をクリックします。

> **Note**
> 万が一、Excel ファイルが認識しないなどエラーが起こった場合は、[Copilot で開始する] から以下の文章を入力し、[生成] してください。
>
> ```text
> テーブル名は[サポートチケット]とします。
> 以下の列を追加してください：
> 依頼者、電子メール、問い合わせ内容、カテゴリ、回答、進捗状況
> ```

## 2.3. テーブル名を確認・変更する

しばらくするとデータワークスペースにテーブルが表示されますので、テーブルの名前を確認します。

> **Note**
> 今回、演習上想定されるテーブルの名前は [サポートチケット] です。名前は実行のたびに異なる場合があります。違うテーブルの名前になった場合は、進行の関係上、[サポートチケット] に変更してください。

1. テーブルを選択し、[プロパティ] をクリックします。
2. 表示名を `サポートチケット` に変更し、任意のスキーマ名 (例: `STtbl`) を設定して [保存] をクリックします。

## 2.4. 列のデータ型を調整する

1. テーブルを選択し、[データを表示する] をクリックして、テーブルの列やデータを表示します。
2. [先頭行をヘッダーとして使用する] をオンにします。
3. [問い合わせ内容] 列の横にあるドロップダウンを選択し、[列の編集] を選択します。[データの種類] を [テキスト] > [複数行テキスト] > [プレーンテキスト] に設定し、[更新] をクリックします。

   > **Note**
   > 列名は、インポート結果によってそれぞれ異なる場合があります。

4. [進捗状況] 列の横にあるドロップダウンを選択し、[列の編集] を選択して、[データの種類] に [選択肢] を選択します。
5. 列の編集ペインで [選択肢(複数)] に `未解決`、`解決済み`、`処理中` を設定します。[既定の選択肢] を [未解決] に設定し、[更新] をクリックします ([値] は既定のままで構いません)。
6. 右上の [保存して終了] をクリックし、[作業が完了した場合] ウィンドウで [保存して終了] をクリックして、テーブルを保存します。

## 2.5. オートナンバー列 (SRID) を追加する

新規のサポートチケットの ID を自動採番し格納するため、オートナンバー列を追加します。

1. テーブルの一覧で [カスタム] タブをクリックし (あるいは右上の検索ボックスでテーブル名を入力して検索)、先ほど作成した [サポートチケット] テーブルをクリックします。
2. 右側の [編集] をクリックします。
3. [+ 新しい列] をクリックし、以下の内容を設定して [保存] をクリックします。

   | 項目 | 値 |
   | --- | --- |
   | 表示名 | SRID |
   | データの種類 | [オートナンバー] |
   | 接頭辞 | SR |

これにより、レコード追加時に `SR-1001` のような ID が自動採番されます。
