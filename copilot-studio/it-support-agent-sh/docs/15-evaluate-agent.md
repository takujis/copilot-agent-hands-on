# 7. エージェントのパフォーマンスを評価する (任意)

エージェントの動作に影響を与える項目は多岐にわたります。指示や、各ツールの説明文などがあり、特に初期には試行錯誤が必要な場合もあります。それぞれの指示文や設定内容を変更して A/B テストなどを模索する場合に、この評価機能が有効に働きます。特に「どの AI モデルを使うべきか」「そのモデルを使う場合の有効な指示文はどうすればよいか」を模索する場合に使用すると、効率的にたどり着くことができます。

## 7.1. テストセットを準備する

この演習で使用する [評価用テストセット.xlsx](../assets/評価用テストセット.xlsx) をあらかじめダウンロードして、PC に保存してください。

こちらは `.xlsx` ファイルです。一度 Excel で開いてから、[名前を付けて保存] で **[CSV UTF-8 (コンマ区切り) (*.csv)]** という形式で保存し直しておいてください。

## 7.2. テストセットを作成する

1. エージェントのページで、[評価] タブをクリックします。
2. [テスト セットを作成する] をクリックします。
3. [データ型] で [単一応答] を選択します。
4. [データ ソース] の点線枠に、7.1 で保存した CSV ファイルをドラッグするか、枠内をクリックしてファイルをアップロードします。
5. [ファイルが正常にアップロードされました。] と表示され、[テスト ケースをレビューする (5 件)] の一覧に、5 件の [質問] と [想定される応答] が正しく取り込まれていることを確認します。

## 7.3. テスト方法を設定する

1. 画面右側の [テスト セットを構成する] で、[名前] を確認し、必要に応じて変更します。
2. [テスト方法] で、[回答品質] の右にあるごみ箱アイコンをクリックし、このテスト メソッドを削除します。
3. [テスト メソッドの追加] をクリックします。
4. [テスト メソッドの選択] で [意味の一致] を選択し、[次へ] をクリックします。
5. [合格点の設定] で `60` を設定し、[OK] をクリックします。

## 7.4. 評価を実行する

1. 同じ画面右側の [ユーザー プロファイル] にある [管理] をクリックし、現在サインインしているユーザーのナレッジやツールへの接続設定を確認し、必要な設定を完了します。
2. 右下の [実行] をクリックして、評価を開始します。評価を開始せずに設定だけを保存する場合は、[保存] をクリックします。
3. 評価が完了するのを待ちます。
4. 評価が完了しましたら、クリックして開きます。
5. テスト実行結果を確認します。結果が [失敗] の内容を確認し、エージェントを修正します。

> **補足**
> [意味の一致] のテスト メソッドは、テストセットに記載した期待する回答と、エージェントの実際の回答の意味的な近さをスコア化します。合格点 (ここでは 60) を下回ったものが [失敗] として一覧に表示されるので、その内容を見て [指示] やツールの説明文を調整し、再度評価を実行します。
