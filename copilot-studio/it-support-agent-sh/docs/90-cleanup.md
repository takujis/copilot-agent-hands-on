# 9. エージェントや環境を削除する

ハンズオン終了後、作成したエージェントや環境を削除する場合の手順です。

## 9.1. Microsoft 365 Copilot アプリ内のエージェントをアンインストールする

1. Microsoft 365 Copilot アプリ画面で、該当のエージェントを選択し、[...] > [アンインストール] をクリックします。
2. 確認画面で [アンインストール] をクリックします。

## 9.2. 環境からエージェントを削除する

1. Copilot Studio <https://copilotstudio.microsoft.com/> にアクセスします。
2. 該当のエージェントを開き、右上の [...] アイコンから [削除] をクリックします。
3. エージェントの名前を入力し、[エージェント の削除] をクリックします。

## 9.3. Power Platform 環境を削除する

1. Power Platform 管理センター <https://admin.powerplatform.microsoft.com/> にアクセスします。
2. 該当の環境を選択し、[削除] をクリックします。
3. 環境名を入力し、[確認] をクリックします。

> **Note**
> 環境を削除すると、その環境内の Dataverse テーブル、フロー、エージェントもすべて削除されます。削除前に、残しておきたいデータがないか確認してください。
