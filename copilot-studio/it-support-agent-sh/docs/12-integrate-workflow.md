# 4. エージェントフローを作成する

この節では、エージェントフローをツールとして登録し、サポートチケットの発行を自動化します。問い合わせを効率化し、Dataverse でデータを記録し、電子メールを自動送信するフローを作成します。

## 4.1. フローを新規作成する

1. エージェントの概要から、[ツール] セクションで [＋ツールを追加する] をクリックします。
2. [ツールを追加する] ウィンドウで、[新規追加] の [ワークフロー] をクリックします。

> **画面の見え方**
> エージェントフローのデザイナー画面は、上から下へノードが縦に連なるフローチャート形式です。最上部がトリガー ノード、その下にアクション ノードが並び、ノードとノードの間にある [+] をクリックすると新しいアクションを挿入できます。ノードをクリックすると、右側 (または下部) に設定用のパネルが開きます。

## 4.2. トリガーに入力パラメーターを追加する

1. デザイナー画面の最上部の [エージェントがフローを呼び出したとき] トリガーをクリックし、 [+入力を追加する] をクリックします。
2. 入力の種類として [テキスト] を選択し、パラメーター名を `Name` にします。
3. 同じ手順で、`Email`、`Details` を作成します。

最終的に、トリガーには次の 3 つのテキスト入力が設定されます。

| パラメーター名 | 種類 | 用途 |
| --- | --- | --- |
| Name | テキスト | 依頼者名 |
| Email | テキスト | 依頼者のメールアドレス |
| Details | テキスト | 問い合わせ内容 |

## 4.3. Dataverse に行を追加する

1. トリガー ノードの下で [＋] をクリックし、[アクションを追加する] の検索ボックスに `新しい行` と入力し、Dataverse の [新しい行を追加する] をクリックします。

   > **Note**
   > 接続の作成を求められた場合は、[新しく追加する] から [サインイン] して接続を作成します。サインイン用のウィンドウがブロックされる旨のエラーが表示される場合は、ブラウザでポップアップを許可してください。

2. [新しい行を追加する] で、[Table name] のプルダウンで `サポートチケット` を検索して選択し、詳細パラメーターで [すべて表示] をクリックします。
3. [詳細パラメーター] の下にテーブルの列がリストされているので、特定の列をクリックし、動的コンテンツボタン (サンダーボルトのアイコン) を使用して入力を追加します。まずは [依頼者] 列を探して、動的コンテンツとして [エージェントがフローを呼び出したとき] の [Name] をクリックします。
4. 同様に、次のとおり設定します。

   | Dataverse の列 | 設定する動的コンテンツ |
   | --- | --- |
   | 依頼者 | [エージェントがフローを呼び出したとき] の `Name` |
   | 問い合わせ内容 | [エージェントがフローを呼び出したとき] の `Details` |
   | 電子メール | [エージェントがフローを呼び出したとき] の `Email` |

## 4.4. メールを送信する

1. [新しい行を追加する] アクション ノードの下の [+] をクリックし、[アクションを追加する] の検索ボックスに `メールの送信` を入力して検索し、[Office 365 Outlook] の [メールの送信(V2)] をクリックします。

   > **Note**
   > 接続の作成を求められた場合は、[サインイン] して接続を作成します。

2. [メールの送信(V2)] アクションの設定を行います。宛先で [設定] (歯車) アイコン > [動的なコンテンツを使用する] をクリックして、[宛先]ボックスに動的コンテンツとして [エージェントがフローを呼び出したとき] の [Email]を設定します。 
3. 件名に以下を設定します。

   ```text
   新しいサポートチケットを発行しました
   ```

4. 本文に以下を設定します。

   ```text
   新しいテクニカルサポートチケットがシステムに登録されました。

   サポートチケットのID: {Dataverse新しい行を追加する内のSRID}
   従業員名: {エージェントがフローを呼び出した時のName}
   技術的な問題: {エージェントがフローを呼び出した時のDetails}
   この件に迅速に対応していきますので、しばらくお待ちください。

   よろしくお願いいたします。
   ```

   > **Note**
   > 上記の `{ }` で囲まれた部分は、そのまま文字列として入力するのではなく、動的コンテンツに置き換えます。それぞれの位置にカーソルを移動して、動的コンテンツボタン (サンダーボルトのアイコン) を使い、次のとおり挿入してください。
   >
   > | 置き換え箇所 | 挿入する動的コンテンツ |
   > | --- | --- |
   > | `{Dataverse新しい行を追加する内のSRID}` | [新しい行を追加する] の `SRID` |
   > | `{エージェントがフローを呼び出した時のName}` | [エージェントがフローを呼び出したとき] の `Name` |
   > | `{エージェントがフローを呼び出した時のDetails}` | [エージェントがフローを呼び出したとき] の `Details` |
   >
   > 動的コンテンツとして挿入されると、その部分はプレーンな文字ではなく、色付きのトークン (タグ) として表示されます。

## 4.5. エージェントへの応答を設定する

1. フローの [Respond to the agent] アクションをクリックします。
2. [+ 出力を追加する] をクリックして、[テキスト]を選択、パラメータの名前を `SRID` とし、[応答に使用する値]ボックスに動的コンテンツとして [新しい行を追加する] の [SRID] を設定します。

## 4.6. フローを保存・公開する

1. 右上にある [下書きを保存する] をクリックします。
2. 概要タブに移動し、[編集] をクリックします。
3. フローの名前を変更します。ここでは `Create a ticket` として保存します。
4. [デザイナー] タブに移動し、トップバーの [公開] をクリックしてフローを公開します。

## 4.7. フローをツールとしてエージェントに登録する

1. エージェントの編集画面に戻り、再び [+ ツールを追加する] をクリックします。
2. 中段の[ワークフロー] を選択し、作成したエージェントフロー [Create a ticket] が表示されるので、クリックします。
3. 次の画面で [追加と構成] をクリックします。
4. [詳細] セクションで以下を入力します。

   | 項目 | 値 |
   | --- | --- |
   | 名前 | チケット発行 |
   | 説明 | SRチケット、サポートチケットを発行します |

   > **補足**
   > ツールの [説明] は、エージェントがどのような場合にこのツールを呼び出すかを判断する材料になります。ユーザーが使いそうな言い回しを含めておくことが重要です。

5. [入力] セクションでは、このエージェントフローの入力パラメーターが表示されています。まずは、[Name] の入力で使用するものとして [カスタム値] を設定します。
6. 次に、値としてシステム変数を設定します。[Name] の [値] の右の [...] から変数の選択画面を表示して、[システム] タブから検索ボックスに `user` と入力して検索し、[User.DisplayName] をクリックします。
7. 同様に、[Email] に [User.Email] を設定します
8. [Details] では、[AI で動的に入力する]の状態のまま、値列の [カスタマイズ] をクリックします。
9. [Details] の [説明] に `問い合わせの内容` を入力し、保存します。
10. [完了] セクションでは、このツールの出力を設定します。ここでは、[実行後] のドロップダウンから [生成AIで応答を記述する] を選択し、右上の [保存] をクリックします。

## 4.8. 指示を修正する

1. エージェントのページで、[概要] タブをクリックして概要ページを開きます。
2. [指示] セクションで [編集] をクリックします。
3. 以下に書き換えて保存します。

   ```text
   # 目的
   このエージェントは、IT部門のサポートエージェントとして、ユーザーからの社内のITに関する質問に対してのみ、迅速かつ正確に回答することを目的としています。エージェントは社内ドキュメントを検索し、適切な回答を提供します。もし適切な回答が見つからない場合は、サポートチケットを発行します。
   # 機能
   ## 社内ITに関する質問への回答
   - ユーザーの質問に対してナレッジソースから情報のみを検索し回答します。情報がない場合に一般的な回答や推測での回答を作成することはしないでください。フォールバックは使用しないでください。
   - ナレッジに情報が見つからない場合は、サポートチケットの発行を促してください。
   - サポートチケットを発行するときは、必ずユーザの同意を得て実行してください。
   ## ITに関連しない質問への回答
   回答せずに、このエージェントでは範囲外なので、担当部署に問い合わせるように促してください。
   ```

## 4.9. エージェントをテストする

1. エージェントのテストから、次のプロンプトを入力します。

   ```text
   マニュアル作成で使用してよい画面録画ツールはありますか
   ```

2. 該当する情報が見つからず、この質問に対してユーザーが求める回答が返されない動作が想定されます。サポートチケットの発行を案内されたら、`はい` や `サポートチケットを発行してください` を意味する内容を入力するなどして、サポートチケットの発行を依頼します。

   > **Note**
   > 接続の確認ダイアログが表示される場合は、[許可] をクリックして接続します。

3. 受付メールが実際に届いていること、Dataverse のサポートチケットテーブルにレコードが作成されていることを確認してください。

   > **Note**
   > サポートチケットテーブルのレコードを確認するには、Power Apps <https://make.powerapps.com> にアクセスし、サポートチケットテーブルの画面を開き、右の [編集] をクリックします。また、上部の [最新の情報に更新] をクリックすると、最新の情報が表示されます。
