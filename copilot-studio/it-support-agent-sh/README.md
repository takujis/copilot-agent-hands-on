# IT サポート エージェント (Copilot Studio)

Microsoft Copilot Studio を使用して、架空の企業で社内システムに関する問い合わせサポートを従業員向けに提供する、簡単なエージェントを作成します。ナレッジで回答できない問い合わせは、エージェントフローでサポートチケットを自動発行します。

## このハンズオンで学べること

- Dataverse テーブルの作成 (Excel インポート、列の型変更、オートナンバー列)
- エージェントの作成と [指示] / モデル / 生成 AI 設定
- ナレッジの追加 (Word ファイル、Dataverse テーブル、同義語・用語集)
- トピックの編集
- エージェントフローをツールとして登録し、Dataverse への記録とメール送信を自動化
- プロンプトツールによる問い合わせ内容のカテゴライズ
- 他のエージェントへの接続 (マルチエージェント)
- エージェントの評価 (プレビュー)
- Microsoft 365 Copilot / Teams への公開と、環境のクリーンアップ

## 使用するファイル

| ファイル | 用途 |
| --- | --- |
| `assets/SupportTicket.xlsx` | Dataverse の [サポートチケット] テーブルを作成するためのインポート元 |
| `assets/EndUser_IT_FAQ.docx` | エージェントのナレッジ (社内 IT の FAQ) |
| `assets/評価用テストセット.xlsx` | エージェント評価用のテストセット (CSV UTF-8 に保存し直して使用) |

> **Note**
> 上記のファイルは `assets` フォルダーに配置してください。演習を始める前に、ローカル PC にダウンロードしておきます。

## 注意事項

- 本手順は IT サポート エージェントのベストプラクティスを示すものではありません。社内 IT サポートを題材に、エージェント作成を体験することを目的としています。
- この演習では、Power Platform の既定以外の "環境" が必要になります。[事前準備](docs/01-prerequisites.md) で作成するか、自分の開発用に作成してある環境をお使いください。
- 一部、本資料作成時点でプレビューの機能を使用しますので、動作が不安定な場合があります。
- Copilot Studio 試用版ライセンスでは、エージェントを公開することはできません。公開が必要な演習はスキップ可能です。
