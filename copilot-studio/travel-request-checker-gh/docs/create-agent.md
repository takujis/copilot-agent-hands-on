# エージェントを作成する

この手順では、出張申請を社内規定に基づいてチェックするエージェントを作成します。

このエージェントは、出張申請内容の不備や社内規定との不一致、費用見積りの問題点を確認し、申請者にフィードバックを提供します。なお、申請の承認や却下は行いません。

## Travel Request Checker を作成する

1. Copilot Studio にアクセスします。

   ```text
   https://copilotstudio.microsoft.com
   ```

> [!NOTE]
>
> この手順では、Copilot Studio の新しいエクスペリエンスを使用して、エージェントを作成します。
>
> クラシック エクスペリエンスが表示される場合は、ホームページで上部の **[今すぐ試す]** をクリックして切り替えてください。

2. 環境セレクターで、使用する Power Platform 環境を選択します。

3. 左側のナビゲーションから [Agents] を選択し、[New agent] をクリックします。

   または、[New agent] のドロップダウン メニューから [Agent] (Uses credits) をクリックします。

4. エージェント デザイナーのツールバーの [...] をクリックし、[Settings] をクリックします。

5. [Agent settings] ダイアログで、[Primary language] に [Japanese] を選択します。

6. [Agent settings] ダイアログを閉じます。

7. [Model] には [Claude Sonnet 4.6] を選択します。

8. エージェント名に以下を入力します。

   ```text
   Travel Request Checker
   ```

## ナレッジを追加する

9. 右側のコンポーネント パネルの [Knowledge] で、[Search all websites] の右側に表示される [×] をクリックします。

   または、[Search all websites] をクリックし、[Add public websites] ダイアログで [Search all websites] をオフにします。

   これで、公開 Web サイトを参照させないようにします。

10. コンポーネント パネルの [Knowledge] で [+] をクリックします。

11. **[海外出張規定.docx](../assets/海外出張規定.docx)**  ファイルをアップロードし、[Add to agent] をクリックします。

> [!NOTE]
> テストを実施する前に、[Knowledge] に追加した `海外出張規定.docx` をクリックし、[Status] が **Ready** になっていることを確認してください。

### スキルを追加する

12. コンポーネント パネルの [Skills] で [+] をクリックします。

13. [Add skill] ダイアログの [Upload a skill] タブで、以下のスキルをアップロードします。

    - [extract-travel-request-details.md](../assets/extract-travel-request-details.md)
      - 出張申請書から基本情報を抽出する
    - [extract-and-check-travel-expense-estimate.md](../assets/extract-and-check-travel-expense-estimate.md)
      - 経費見積の内容を抽出し確認する
    - [check-travel-policy-compliance.md](../assets/check-travel-policy-compliance.md)
      - 社内規定との整合性を確認する

### インストラクションを設定する

14. [Instructions] に以下を入力します。

    ```text
    あなたは Travel Request Checker です。
    
    ユーザーがアップロードした出張申請書を確認し、申請内容の不備、経費見積の問題、社内規定との不一致の可能性をチェックしてください。
    
    あなたの役割は、出張申請書の内容を確認し、問題点や確認事項をユーザーに分かりやすく提示することです。
    申請の承認、却下、最終判断は行わないでください。
    
    以下の観点で確認してください。
    
    1. 出張申請書から基本情報を抽出する
    2. 経費見積を抽出し、合計金額を確認する
    3. ナレッジに含まれる社内規定に基づいて、申請内容をチェックする
    4. 不備、未記入、金額の不整合、規定との不一致がある場合は指摘する
    
    注意事項:
    - 推測で情報を補完しないでください。
    - 承認や却下の判断は行わず、チェック結果として問題点や確認事項を提示してください。‌‌
    - 関連するイベント案内、実施計画書、アジェンダ、招待メール等が見つかった場合は、記載内容との整合性を確認してください。
    - 関連資料が見つからない場合は、レビューに必要な情報が不足している可能性があるため、ユーザーに関連資料の有無を確認してください。
    - ユーザーが関連資料を保有している場合は、添付を依頼してください。
    - 調査を行っても判断に必要な情報が見つからない場合のみ、「不明」または「追加確認が必要」と表示してください。
    ```

15. エージェントを保存します。(右上の [保存] アイコンをクリックするか、`Ctrl` + `S` で保存します。)

## エージェントをテストする

1. サンプルの [**出張申請書**](../assets/海外出張申請書_sample.xlsx) と [**出張関連資料**](../assets/Asia_Leadership_Offsite_2026_案内_sample.docx) をダウンロードします。

2. 上部の [Preview] タブを選択します。

> [!NOTE]
> - エージェントの動きを詳細に確認する場合は、[End user preview] をオフにしてください。
> - 会話のコンテキストをリセットする場合は、[New chat] をクリックします。

3. チャット入力欄に **出張申請書** ファイルを添付し、送信します。

   ```text
   レビューしてください
   ```

4. 出張に関連するファイルの添付・提出を求められた場合は、**出張関連資料** ファイルを添付し、送信します。

5. エージェントの回答内容を確認し、追加の出張関連資料をもとに出張申請の内容がチェックされているかを確認します。
