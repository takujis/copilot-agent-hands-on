# Device Assistant にデバイス交換申請機能を実装する

ここまでの手順で、デバイスに関する問い合わせに回答する Device Assistant を作成しました。

この手順では、担当者による確認や他システムとの連携を想定したデバイス交換申請のフローを構築します。

Device Assistant で交換申請に必要な情報を収集し、申請処理を行えるように構成します。

## SharePoint でデバイス交換申請リストを作成する

ハンズオンで利用可能な SharePoint サイトを用意し、以下のリストを作成します。

- リスト名

  ```text
  デバイス交換申請
  ```

- 列

  | 列名 | 種類 |
  |------|------|
  | 申請者 | 1 行テキスト |
  | 申請者メールアドレス | 1 行テキスト |
  | 対象デバイス | 1 行テキスト |
  | 交換理由 | 複数行テキスト |

> [!NOTE]
>
> SharePoint リストの既定の Title 列を、`申請者` に名前を変更して使用します。

## Device Replacement Request Flow を作成する

1. Copilot Studio の左側のナビゲーションから [フロー] を選択します。

2. [新しいエージェント フロー] をクリックします。

### トリガーを設定する

3. [ワークフローの作成] で [エージェントがフローを呼び出したとき] トリガーを検索して追加します。

4. [エージェントがフローを呼び出したとき] ノードで以下の入力を追加します。

   | 名前 | 種類 |
   |------|------|
   | device | テキスト |
   | replacementReason | テキスト |

### アクションを追加する

5. [+] > [アクションを追加する] から、[マイ プロフィールの取得 (V2)] (Office 365 ユーザー) を検索して追加します。

   既存の接続参照を選択するか、新しく作成します。

6. [+] > [アクションを追加する] から、[項目の作成] (SharePoint) を検索して追加します。

   既存の接続参照を選択するか、新しく作成します。

7. パラメーターに値を設定します。

   | 項目 | 値 |
   |------|------|
   | サイトのアドレス | デバイス交換申請リストがあるサイトのアドレス |
   | リスト名 | デバイス交換申請 |
   | 申請者 | `{表示名}` |
   | 申請者メールアドレス | `{メール}` |
   | 対象デバイス | `{device}` |
   | 交換理由 | `{replacementReason}` |

   [申請者]、[申請者メールアドレス]、[対象デバイス]、[交換理由] については、[詳細パラメーター] の [すべて表示] をクリックして表示し、設定します。

   `{メール}`、`{表示名}` には、[マイ プロフィールの取得 (V2)] の出力から対応する動的コンテンツを挿入します。

   `{device}`、`{replacementReason}` には、[エージェントがフローを呼び出したとき] の出力から対応する動的コンテンツを挿入します。

8. [+] > [アクションを追加する] から、[メールの送信 (V2)] (Office 365 Outlook) を検索して追加します。

   既存の接続参照を選択するか、新しく作成します。

9. [宛先]、[件名] に以下を入力します。

   | 項目 | 値 |
   |------|------|
   | 宛先 | `{メール}` |
   | 件名 | デバイス交換申請を受け付けました |

   `{メール}` には、[マイ プロフィールの取得 (V2)] の出力から対応する動的コンテンツを挿入します。

10. [本文] に以下を入力します。

    ```text
    デバイス交換申請を受け付けました。
    
    申請者: {表示名} ({メール})
    対象デバイス: {device}
    交換理由: {replacementReason}
    ```

    `{メール}`、`{表示名}` の文字列を削除し、[マイ プロフィールの取得 (V2)] の出力から対応する動的コンテンツを挿入します。

    `{device}`、`{replacementReason}` の文字列を削除し、[エージェントがフローを呼び出したとき] の出力から対応する動的コンテンツを挿入します。

11. [+] > [アクションを追加する] から、[エージェントに応答する] を検索して追加します。

12. [エージェントに応答する] ノードで以下の出力を追加します。

    | 名前 | 種類 | 値 |
    |------|------|------|
    | requestStatus | テキスト | Submitted |

13. [下書きを保存する] をクリックして、エージェントフローを保存します。

### エージェントフローを保存して公開する

14. [概要] タブを開き、フロー名を以下に変更して保存します。

    ```text
    Device Replacement Request Flow
    ```

15. [デザイナー] タブを開き、[公開] をクリックしてエージェントフローを公開します。

16. [概要] タブを開き、[接続参照] の [管理] をクリックし、[Office 365 ユーザー] および [Office 365 Outlook] で使用する接続を [実行専用のユーザーによって提供されました] に設定して保存します。

## Device Assistant に Device Replacement Request Flow を追加する

1. Device Assistant を開きます。

### デバイス交換申請トピックを作成する

2. [トピック] タブを開き、[トピックの追加] > [最初から] をクリックします。

3. トピック名に以下を入力して設定します。

    ```text
    デバイス交換申請
    ```

4. 上部の [詳細] アイコンをクリックしてトピックの詳細を開き、[入力] タブで以下の変数を追加します。

   | 変数名 | 変数のデータ型 | 説明 |
   |------|------|------|
   | device | String | 対象デバイス |
   | replacementReason | String | 交換理由 |

   [エージェントはこの入力にどのように情報を入力しますか?] には、[最適なオプションを動的に入力する (既定)] を選択します。

5. 追加した各入力変数で [追加設定] を展開し、[ユーザーに求める必要がある] のチェックをはずします。

6. トリガーの [トピックの機能を説明する] に以下を入力します。

    ```text
    ユーザーがデバイス交換申請を希望した場合に起動します。
    ```

7. [+] から [メッセージを送信する] を追加し、以下を入力して設定します。

    ```text
    デバイス交換申請に進みます。
    ```

8. [+] から [アダプティブ カードで質問する] を追加し、[...] > [プロパティ] からプロパティを開き、[アダプティブ カードを編集する] > [カード ペイロード エディター] に以下を入力して保存します。

   ```text
   {
     "$schema": "https://adaptivecards.io/schemas/adaptive-card.json",
     "type": "AdaptiveCard",
     "version": "1.5",
     "body": [
       {
         "type": "TextBlock",
         "text": "デバイス交換の申請内容を入力してください。",
         "wrap": true
       },
       {
         "type": "Input.Text",
         "id": "device",
         "label": "対象デバイス",
         "isRequired": true,
         "errorMessage": "対象デバイスを入力してください。"
       },
       {
         "type": "Input.Text",
         "id": "replacementReason",
         "label": "交換理由",
         "isMultiline": true,
         "isRequired": true,
         "errorMessage": "交換理由を入力してください。"
       }
     ],
     "actions": [
       {
         "type": "Action.Submit",
         "title": "送信"
       }
     ]
   }
   ```

9. [アダプティブ カード ノード のプロパティ] で [形式] を [式] に変更します。

10. device 入力の定義に以下のプロパティを追加します。

    ```text
    value: Topic.device,
    ```
    
    以下のようになります。
    
    ```text
    {
      type: "Input.Text",
      id: "device",
      label: "対象デバイス",
      value: Topic.device,
      isRequired: true,
      errorMessage: "対象デバイスを入力してください。"
    }
    ```

11. replacementReason 入力の定義に以下のプロパティを追加します。

    ```text
    value: Topic.replacementReason,
    ```
    
    以下のようになります。
    
    ```text
    {
      type: "Input.Text",
      id: "replacementReason",
      label: "交換理由",
      value: Topic.replacementReason,
      isMultiline: true,
      isRequired: true,
      errorMessage: "交換理由を入力してください。"
    }
    ```

12. [+] から [ツールを追加する] > [基本ツール] タブ > [Device Replacement Request Flow] を追加し、[入力] で以下を設定します。

    | 入力 | 値 |
    |------|------|
    | device (String) | `device` (Topic.device) |
    | replacementReason (String) | `replacementReason` (Topic.replacementReason) |

13. [+] から [メッセージを送信する] を追加し、以下を入力して設定します。

    ```text
    デバイス交換申請を受け付けました。
    対象デバイス: {device}
    交換理由: {replacementReason}
    ```
    
    `{device}`、`{replacementReason}` の文字列を削除し、それぞれの位置に、[変数を挿入する] アイコンをクリックし、[カスタム] タブで該当する変数を選択して挿入します。

14. [保存] をクリックして、トピックを保存します。

### Device Assistant の指示を更新する

15. Device Assistant の [指示] を編集します。「回答方針」セクションの後に、以下を追加して保存しします。

    ```text
    # デバイス交換
    
    ユーザーが交換したい、交換を申請したい、デバイスを交換したい、代替機が欲しいなど、デバイス交換の意思を示した場合は、{デバイス交換申請} を実行すること。
    
    ## デバイス交換申請後の応答

    デバイス交換申請後は、デバイス交換申請に関するメッセージを追加で出力しないこと。
    ```

    `{デバイス交換申請}` の文字列を削除し、その位置に、[追加] をクリック (または、半角スペース + `/` を入力) して該当トピックの参照を追加します。

## エージェントをテストする

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   デバイスを交換したいです。
   ```

2. 表示されたフォームに申請内容を入力して送信します。

> [!NOTE]
>
> [Office 365 Outlook] や [Office 365 Users] の接続を求められた場合は、[許可] をクリックして続行します。

3. エージェントの応答を確認します。

   あわせて、SharePoint のデバイス交換申請リストのアイテムと送信されたメールを確認します。

4. [+] をクリックして、新しいチャットを開始します。

5. チャット入力欄に以下のようなメッセージを入力して送信します。

   ```text
   Surface Laptop が起動しないため、交換を申請したいです。
   ```

6. 表示されたフォームに申請内容を入力して送信します。

   直前のメッセージから対象デバイスや交換理由が特定されて値がセットされている場合、必要に応じて編集して送信します。

7. エージェントの応答を確認します。

   あわせて、SharePoint のデバイス交換申請リストのアイテムと送信されたメールを確認します。
