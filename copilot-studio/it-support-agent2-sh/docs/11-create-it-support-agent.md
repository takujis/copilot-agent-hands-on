# IT Support Agent を作成する

この手順では、社内 IT に関する問い合わせに対応する IT Support Agent を作成し、基本の設定を行います。

## エージェントを作成する

1. Copilot Studio にアクセスします。

```text
https://copilotstudio.microsoft.com
```

2. 環境セレクターで、使用する Power Platform 環境を選択します。

3. 左側のナビゲーションから [エージェント] を選択し、エージェントを作成します。

   - 新しいエクスペリエンスの場合
     - [新しいエージェント] のドロップダウン メニューから [エージェント] (標準) をクリックします。

   - クラシック エクスペリエンスの場合
     - [空のエージェントを作成する] をクリックします。

> [!NOTE]
>
> 新しいエクスペリエンスからクラシック エクスペリエンスに切り替える場合は、ホームページで上部の **[New experience]** トグルをオフにします。
>
> クラシック エクスペリエンスから新しいエクスペリエンスに切り替える場合は、ホームページで上部の **[今すぐ試す]** をクリックします。

4. エージェントの名前と言語を設定し、[作成] をクリックします。

   | 項目 | 設定内容 |
   |------|------|
   | 名前 | IT Support Agent (Standard) |
   | 言語 | 日本語 (日本) |

   [エージェント設定 (オプション)] を展開すると、言語の設定が表示されます。

5. 右上の [設定] をクリックします。

6. [生成 AI] > [オーケストレーション] で、[エージェントの応答に生成 AI オーケストレーションを使用しますか?] で [はい] が選択されていることを確認します。

7. [生成 AI] > [ナレッジ] で、[根拠のない応答を許可する] および [Webの情報を使用する] をオフにします。

8. 下部の [保存] をクリックして保存し、設定を閉じます。

9. エージェントの [説明] に以下を入力し、保存します。
   
   ```text
   社内 IT に関するお問い合わせに対応するサポートエージェントです。ナレッジ検索、サポートチケットの作成、チケットの状態確認を支援します。
   ```

10. エージェントのモデルとして [Claude Sonnet 4.6] を選択します。

11. [指示] に以下を入力し、保存します。

    ```text
    # 目的

    このエージェントは、社内 IT サポートに関する問い合わせに回答します。

    # 回答方針

    - 回答は必ず設定されたナレッジソースのみを使用すること。
    - 一般知識、事前学習済み知識、Web 上の情報、推測を用いて回答してはならない。
    - ナレッジソースに記載されていない内容を補完してはならない。
    ```

12. [ナレッジ] で [ナレッジの追加] をクリックします。

13. **[IT_FAQ.docx](../assets/IT_FAQ.docx)** ファイルをアップロードし、[エージェントに追加する] をクリックします。

> [!NOTE]
>
> テストを実施する前に、ナレッジに追加した **IT_FAQ.docx** の状態が **準備完了** になっていることを確認してください。

## エージェントをテストする

IT Support Agent をテストし、エージェントの動作を確認します。

> [!NOTE]
>
> - エージェントの動きを確認するため、[エージェントをテストする] ペインの上部にある [テスト ウィンドウの展開] アイコンをクリックします。
> 
> - 新しいテスト セッションを開始する場合は、[エージェントをテストする] ペインの上部にある [+] アイコンをクリックします。

1. [エージェントをテストする] ペインのチャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   PC から PDF ファイルを印刷したいのですが、なぜか印刷できません。プリンターの電源は入っています。
   ```

2. エージェントの回答内容を確認します。

   > 期待される動作:
   > - アップロードした IT FAQ のナレッジに基づいた回答が生成されること
