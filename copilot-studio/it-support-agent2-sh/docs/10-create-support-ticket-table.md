# Support Ticket テーブルを作成する

サポートチケット用の Dataverse テーブルを作成します。

1. Power Apps Maker Portal にアクセスします。

   ```text
   https://make.powerapps.com
   ```

2. 環境セレクターで、使用する Power Platform 環境を選択します。

3. 左側のナビゲーションから [テーブル] を選択します。

4. コマンド バーの [新しいテーブル] > [新しいテーブルを作成する] をクリックします。

5. [空白から開始] を選択します。

6. テーブル カード (既定のテーブル名は [テーブル1]) で [...] をクリックし、[プロパティ] をクリックします。

7. [テーブルの編集] ダイアログで以下を設定し、[保存] をクリックします。

   | 項目 | 値 |
   |------|------|
   | 表示名 | Support Ticket |
   | 複数形の名前 | Support Tickets |
   | スキーマ名 (高度なオプション) | SupportTicket |

8. テーブル カードで [...] をクリックし、[データを表示する] をクリックします。

9. 既定で追加されている列 (既定の列名は [新しい列]) をクリックし、[列の編集] をクリックします。

   [列の編集] ダイアログで以下を設定し、[更新] をクリックします。

   | 項目 | 値 |
   |------|------|
   | 表示名 | Title |
   | データの種類 | 1 行テキスト |
   | 書式 | テキスト |
   | スキーマ名 (高度なオプション) | Title |

10. [新しい列] をクリックし、以下を設定して [保存] をクリックします。

    | 項目 | 値 |
    |------|------|
    | 表示名 | Details |
    | データの種類 | テキスト > 複数行テキスト > プレーン テキスト |
    | 書式 | テキスト |
    | スキーマ名 (高度なオプション) | Details |

11. [新しい列] をクリックし、以下を設定して [保存] をクリックします。

    | 項目 | 値 |
    |------|------|
    | 表示名 | Category |
    | データの種類 | 1 行テキスト |
    | 書式 | テキスト |
    | スキーマ名 (高度なオプション) | Category |

12. [新しい列] をクリックし、以下を設定して [保存] をクリックします。

    | 項目 | 値 |
    |------|------|
    | 表示名 | Ticket Status |
    | データの種類 | 選択肢 > 選択肢 |
    | 選択肢 | Open<br>In Progress<br>Resolved<br>Closed |
    | 既定の選択肢 | Open |
    | スキーマ名 (高度なオプション) | TicketStatus |

13. 右上の [保存して終了] をクリックして、テーブルを保存します。

14. 作成した Support Ticket テーブルを開きます。

15. [スキーマ] セクションの [列] をクリックします。

16. サポートチケット番号を自動採番するためのオートナンバー列を追加します。[新しい列] をクリックし、以下を設定して [保存] をクリックします。

    | 項目 | 値 |
    |------|------|
    | 表示名 | Ticket Number |
    | データの種類 | オートナンバー |
    | 接頭辞 | SR |
    | スキーマ名 (高度なオプション) | TicketNumber |

以上で、Support Ticket テーブルの作成は完了です。

> [!NOTE]
>
> 上記の手動作成以外にも、ソリューションをインポートすることで、本ハンズオンで使用する Support Ticket テーブルを準備できます。
>
> **[こちら](../assets/it-support-base)** から、Support Ticket テーブルが含まれるソリューション (*.zip) をダウンロードできます。
