# 前提条件

本ハンズオンでは、Copilot Studio で Standard harness を利用したエージェントを作成します。

実施前に、以下の前提条件を満たしていることを確認してください。

- Microsoft 365 テナント
  - ハンズオンで使用可能な Microsoft 365 テナントをご用意ください。

- Power Apps 開発者プランまたは有効なライセンス
  - 開発者環境を作成し、使用します。

- Microsoft Copilot Studio 試用版または有効なライセンス

- SharePoint サイト
  - リストを作成可能な SharePoint サイトをご用意ください。用意できない場合は、SharePoint を利用する手順をスキップしてください。

> [!IMPORTANT]
> Copilot Studio 試用版ライセンスではエージェントを公開できません。そのため、本ハンズオンの一部の手順を実施できません。公開に関する手順は必要に応じてスキップしてください。
