# 6. 他のエージェントに接続する (任意)

ここまでで、社内システムに関する問い合わせのエージェントを作成しましたが、PC やスマートフォンなどの物理的なデバイスの貸与や返却などに関する問い合わせも来る可能性があります。企業によっては、物理的なデバイスの管理は総務部門など別管理の場合もあるため、ここでは物理デバイスにかかわる問い合わせを別エージェントにして、本サポートエージェントからも呼び出す形をとります。

ここでは簡易な **My Device Support** エージェントを作成し、IT サポート エージェントから呼び出せるようにします。

> **Note**
> Copilot Studio 試用版ライセンスでは、エージェントを公開することはできません。その場合は、この演習をスキップしてください。

## 6.1. My Device Support エージェントを作成する

1. Copilot Studio の左側のナビゲーションから [エージェント] を選択し、[＋空のエージェントを作成する] をクリックします。
2. 名前、説明、指示にそれぞれ以下を入力し、保存します。

### 名前

```text
My Device Support
```

### 説明

```text
従業員の業務用デバイス (PC、スマートフォン、タブレットなど) の返却、廃棄、貸出のリクエストを受け付けるエージェントです。
```

### 指示

```text
以下のリクエストに対応します。
- **デバイスの返却** (退職・部署異動・不要になった場合など)
- **デバイスの廃棄** (故障・老朽化・使用不可など)
- **デバイスの貸出** (一時的な利用・新規プロジェクトなど)

注意点
- 不明確なリクエストには丁寧に確認を行う
- 機密情報や個人情報の取り扱いには注意し、必要以上に聞き出さない
```

## 6.2. 生成 AI の設定を行う

1. 右上の [設定] をクリックします。
2. [生成 AI] > [オーケストレーション] で、[エージェントの応答に生成 AI オーケストレーションを使用しますか?] で [はい] が選択されていることを確認します。
3. [生成 AI] > [接続されたエージェント] で、[他のエージェントがこれに接続し、使用できるようにする] がオンになっていることを確認します。
4. [生成 AI] > [ナレッジ] で、[根拠のない応答を許可する] と [Web の情報を使用する] をオフにします。
5. 下部の [保存] をクリックして保存し、右上の [×] をクリックして設定を閉じます。

## 6.3. トピック「デバイスの返却」を作成する

1. エージェントのページで、[トピック] タブをクリックして、[+ トピックの追加] > [最初から] をクリックします。
2. トピック名を `デバイスの返却` にします。
3. トリガー ノードの [トピックの機能を説明する] で、以下の内容を入力します。

   ```text
   このトピックは、ユーザーがデバイス・機器・PC・周辺機器の「返却」を申請する場合に対してのみ対応します。それ以外のリクエスト「交換」「購入」「廃棄」「貸出」などには応答しません。
   ```

### 質問ノードを追加する

1. トリガー ノードの下で [＋] をクリックし、[質問する] をクリックして、質問ノードを追加します。次の内容を入力します。

   ```text
   デバイスの返却についてお答えします。あなたのオフィスを選択してください。
   ```

2. [特定] で [複数選択式オプション] を選択して設定します。
3. [ユーザーのオプション] で [新しいオプション] をクリックし、`東京オフィス`、`大阪オフィス`、`福岡オフィス` を追加します。

> **画面の見え方**
> 選択肢を 3 つ設定すると、質問ノードの下に選択肢ごとの条件分岐が横並びで自動生成されます。左端が [東京オフィス]、その右が [大阪オフィス]、[福岡オフィス] の条件ノードで、さらに右端に [その他のすべての条件] のノードが並びます。

### 条件ごとにメッセージを設定する

1. 左端の条件ノードで [Var1]、[が次の値に等しい]、[東京オフィス] が設定されていることを確認します。
2. 左端の条件ノード (東京オフィス) の下で [＋] をクリックし、[メッセージを送信する] をクリックして、メッセージ ノードを追加します。次の内容を入力します。

   ```text
   デバイス返却・廃棄は、機器管理窓口に直接お越しください。 {Char(10)}
   場所: Contoso Tokyo ビル 20階 機器管理窓口 {Char(10)}
   営業時間: 月曜日～金曜日 9:00～12:00、13:00～17:00
   ```

   > **Note**
   > `{Char(10)}` は改行を表す数式です。メッセージ ノードで数式として入力します。

3. 右隣の条件ノード 2 つ (大阪オフィスおよび福岡オフィス) を [...] > [削除] をクリックして削除します。
4. [その他のすべての条件] ノードの下で [+] をクリックし、[メッセージを送信する] をクリックして、メッセージ ノードを追加します。次の内容を入力します。

   ```text
   デバイスは、社内便を利用して、東京オフィスまでお送りください。
   ```

5. 上部で [保存] をクリックして、トピックを保存します。

## 6.4. エージェントを公開する

ページ上部の [公開] をクリックし、[このエージェントを公開する] ウィンドウで [公開する] をクリックし、エージェントを公開します。

## 6.5. IT サポート エージェントから接続する

1. この演習で作成した "IT サポート エージェント" のページを開き、[エージェント] タブをクリックします。
2. [+ 追加] ボタンをクリックします。
3. [エージェントの拡張方法を選択します] ウィンドウで、[My Device Support] を選択します。
4. 既定の設定の状態で、[追加と構成] をクリックします。
5. IT サポート エージェントの概要ページで、[指示] に以下の内容を追記します。

   ```text
   ## デバイスの返却、廃棄、貸出の受付
   ユーザーから、デバイスの返却、廃棄、貸出を求められたら、{[My Device Support]} を呼び出します。
   ```

   > **Note**
   > `{[My Device Support]}` の文字列は、そのまま入力するのではなく、半角スペース + スラッシュ (` /`) を入力してオブジェクトの選択肢を表示し、[My Device Support] エージェントを挿入して置き換えます。挿入されると、その部分は色付きのトークン (タグ) として表示されます。

6. [保存] をクリックします。

## 6.6. エージェントをテストする (任意)

[エージェントをテストする] ペインで、次のプロンプトを入力します。

```text
今使っているPCを返却したい
```

IT サポート エージェントから My Device Support エージェントが呼び出され、オフィスの選択が求められることを確認します。
