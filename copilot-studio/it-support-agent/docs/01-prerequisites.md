# 前提条件

本ハンズオンでは、GitHub Copilot harness を利用したエージェントを作成します。

開始する前に、以下を満たしていることを確認してください。

- Power Platform 環境を作成できること
- Copilot クレジットを利用できること (利用する環境への構成が必要です)

> [!IMPORTANT]
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。
>
> これは、エージェントの構築、テスト、評価、および実行に適用されます。

GitHub Copilot harness で動作するエージェントの使用量に基づく請求については、以下をご確認ください。

- [GitHub Copilot ハーネスで動作するエージェントの請求概要](https://learn.microsoft.com/ja-jp/microsoft-copilot-studio/agents-experience/billing-credit-overview)

環境で Copilot クレジットを利用できるように構成する方法については、以下をご確認ください。

- [Copilot Studio のクレジットと容量を管理する](https://learn.microsoft.com/ja-jp/power-platform/admin/manage-copilot-studio-messages-capacity)

Power Platform 環境については、以下をご確認ください。

- [Copilot Studio における Power Platform 環境に関する作業](https://learn.microsoft.com/ja-jp/microsoft-copilot-studio/environments-first-run-experience)

> [!NOTE]
>
> 記載内容は 2026 年 8 月時点の情報に基づいています。
