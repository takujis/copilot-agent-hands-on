# 3. IT サポート エージェントを作成する

## 3.1. エージェントを作成する

1. Copilot Studio <https://copilotstudio.microsoft.com> にブラウザでアクセスします。
2. 右上の [環境] をクリックし、[環境を選択] ウィンドウが表示されたら、使用する Power Platform 環境を選択します。
3. 右上の [環境] で該当の環境が選択されていることを確認します。
4. 左側のナビゲーションから [エージェント] を選択し、[＋空のエージェントを作成する] をクリックします。
5. 名前に以下を入力します。

   ```text
   IT サポート エージェント
   ```

6. [詳細] セクションで [編集] をクリックし、以下の説明を入力して、[保存] をクリックします。

   ```text
   IT サポート エージェントは、ユーザーの問い合わせに対する即時トラブルシューティングを提供し、解決できない問題はサポートチケット作成を自動化します。
   ```

7. [指示] セクションで [編集] をクリックし、以下を入力して、[保存] をクリックします。

   ```text
   # 目的
   このエージェントは、IT部門のサポートエージェントとして、ユーザーからの質問に対して迅速かつ正確に回答することを目的としています。エージェントは社内ドキュメントを検索し、適切な回答を提供します。
   # 機能
   ## 社内ITに関する質問への回答
   社内のITに関する質問を受けたときは、ナレッジソースから情報を検索し、回答を作成してください。直接関係する情報が見つからない場合は、他の情報を使って補完したり、推測で回答したりしないでください。
   ```

> **画面の見え方**
> エージェントの [概要] ページは、[詳細] (名前・説明・アイコン)、[指示]、[ナレッジ]、[ツール]、[トピック]、[エージェント]、[推奨プロンプト] といったセクションが縦に並ぶ構成です。各セクションの右側に [編集] や [+ 追加] のリンクがあります。

## 3.2. モデルを選択する

[エージェントのモデルを選択します] でモデルの選択が可能です。今回は [GPT-5.5 Chat] を使ってみましょう。

## 3.3. 生成 AI の設定を行う

1. エージェントのページ右上の [設定] ボタンをクリックします。
2. [生成 AI] セクションで、[はい、利用できるツールやナレッジを適宜使用し、応答を動的にします。] が選択されていることを確認します。
3. [根拠のない応答を許可する] と [Web の情報を使用する] をオフにし、下部の [保存] ボタンをクリックして保存します。

> **補足**
> この 2 つをオフにすることで、エージェントはナレッジに根拠のある内容だけを回答するようになります。後の演習で「ナレッジに情報がないときはサポートチケットを発行する」動作を確認するための前提設定です。

## 3.4. ナレッジを追加する

ナレッジを追加してエージェントが回答する範囲を強化します。

> **Note**
> この演習で使用する `EndUser_IT_FAQ.docx` をあらかじめダウンロードして、PC に保存してください (本リポジトリでは [`../assets`](../assets) フォルダーに配置しています)。

### Word ファイルを追加する

1. IT サポート エージェントの概要ページで、下にスクロールして [+ ナレッジの追加] ボタンをクリックします。
2. [選択して参照] リンクを選択し、ダウンロードした `EndUser_IT_FAQ.docx` を追加します。
3. [エージェントに追加する] をクリックしてファイルをアップロードします。

### Dataverse テーブルを追加する

1. 再度、エージェントの概要ページに移動し、[+ ナレッジの追加] をクリックします。
2. ナレッジのデータ ソースとして [Dataverse] を選択します。
3. 検索ボックスに `チケット` と入力して検索し、[サポートチケット] テーブルを選択します。
4. [エージェントに追加する] ボタンをクリックし、ナレッジソースを追加します。

> **Note**
> [ナレッジ] ページで、追加されたナレッジ ソースが正常に準備完了になったことを確認します。通常、完了するまでに 10 分から 15 分かかります。準備完了までは "不明" と表示される場合もありますが、完了までお待ちください。

## 3.5. 同義語と用語集を設定する

Dataverse のテーブルをナレッジ登録する場合、テーブルの列名と、ユーザーのプロンプトの文言が意図するところが必ずしも一致しない場合があります。その場合、同義語や用語集を設定することをお勧めします。以下に、今回のシナリオを例にした設定例を記述します。

### 同義語

1. [ナレッジ] ページのナレッジの一覧から、Dataverse の [サポートチケット] をクリックします。
2. [同義語] タブをクリックし、列名 [SRID] で [+ 同義語の追加] をクリックします。
3. [同義語の追加] ウィンドウで `ID` を入力して [追加] をクリックします。
4. 同様に、`SR ID`、`サポートチケット ID`、`チケット ID` を入力して追加し、[完了] をクリックします。
5. SRID の [説明] に以下を入力します。

   ```text
   各サポートチケットのIDで、サポートチケットの追跡や検索に使用します。このIDは、次のように数字と文字の組み合わせで構成されています: SR-1011
   ```

### 用語集

1. [用語集] タブをクリックし、用語と説明に以下を入力して、[追加] をクリックします。

   | 項目 | 値 |
   | --- | --- |
   | 用語 | SR |
   | 説明 | サービスリクエスト、サポートチケットを表します |

2. [保存] をクリックします。

## 3.6. トピックを変更する

ここでは、トピックを修正して動きを確認します。

1. トップメニューバーから [トピック] をクリックし、[すべて] をクリックしてすべてのトピックを表示し、[会話の開始] トピックをクリックして開きます。
2. 下にスクロールして、メッセージノードに移動します。メッセージの全文を以下のように変更します。

   ```text
   こんにちは、{System.User.FirstName}。私は{System.Bot.Name}、社内ITについてサポートを行うアシスタントです。
   ご用件は何ですか？
   例えば、
   - メールの送受信ができない。
   - 社内の共有ドライブやフォルダにアクセスできない。
   - サポートチケット SR-1001 の状況を教えてください。
   ```

   > **Note**
   > `{System.User.FirstName}` と `{System.Bot.Name}` は変数です。メッセージ ノードの入力欄で `{` を入力すると変数の候補が表示されるので、そこから挿入します。

3. 上部の [保存] をクリックして、トピックを保存します。

> **Note**
> ここでは [会話の開始] トピックを使い、サンプルとなるプロンプトを付記しましたが、最終的にチャネルとして Microsoft 365 Copilot で使用する場合、[会話の開始] トピックは動作しません。Microsoft 365 Copilot での使用を考えている場合には、エージェントの [概要] の最下部の [推奨プロンプト] を使用することで、ユーザーがエージェントとの会話を始めやすくします。
>
> 1. エージェントのページで、[概要] タブをクリックして概要ページを開きます。
> 2. 下部の [推奨プロンプト] セクションで、[+ 推奨プロンプトを追加する] をクリックします。
> 3. [タイトル] と [プロンプト] に、ユーザーが会話を始めやすい内容を入力します (例として、上記の [会話の開始] メッセージに記載した問い合わせ例をそのまま利用できます)。
> 4. [保存] をクリックします。
>
> なお、エージェントのテストでは、推奨プロンプトを表示、使用することができません。

## 3.7. エージェントをテストする

1. 右上の [テスト] アイコンをクリックして、[エージェントをテストする] ペインを表示します。
2. [+] アイコンあるいは [+ 新しいテスト セッションを開始する] をクリックし、新しいテスト セッションを開始します。
3. 以下のプロンプトを入力します。

   ```text
   プリンターが機能していません それを修正する方法をおしえてください
   ```

4. ナレッジソース (Word ファイル) に従って回答が提供されていることを確認します。

> **Note**
> 活動マップは、セッション中に発生した入力、決定、反応のフローを視覚的に表現したものです。テスト中に活動マップを表示するには、[テスト時に活動マップを表示する] をオンにします。オンにしても自動的に活動マップが表示されない場合は、[テスト ウィンドウの展開] アイコンをクリックします。

5. [+] アイコンあるいは [+ 新しいテスト セッションを開始する] をクリックし、次に以下のプロンプトを入力します。

   ```text
   マニュアル作成で使用してよい画面録画ツールはありますか
   ```

6. 該当するナレッジがないため、この質問に対してユーザーが求める回答が返されないことを確認します。
