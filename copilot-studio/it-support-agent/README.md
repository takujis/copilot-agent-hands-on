# IT サポート エージェント (Srandard Harness)
## 概要
このハンズオンでは、Microsoft Copilot Studio を使用して、架空の企業における社内 IT に関する問い合わせに対応するエージェントを作成します。

エージェントの作成を通じて、Microsoft Copilot Studio の基本的な操作方法や主要な機能について学習します。

> [!IMPORTANT]
>
> 本手順は IT サポート エージェントの設計や実装に関するベストプラクティスを示すものではありません。
>
> 社内 IT サポートを題材として、Microsoft Copilot Studio を利用したエージェント作成を体験し、主要な機能や操作方法を学習することを目的としています。

> [!IMPORTANT]
> 
>Copilot Studio 試用版ライセンスでは、エージェントを公開することはできません。公開が必要な演習はスキップ可能です。
> 
## このハンズオンで学べること

- Dataverse テーブルの作成 (Excel インポート、列の型変更、オートナンバー列)
- エージェントの作成（指示 / モデル / 生成 AI 設定）
- ナレッジの追加 (Word ファイル、Dataverse テーブル、同義語・用語集)
- トピックの編集
- エージェントフローをツールとして登録し、Dataverse への記録とメール送信を自動化
- プロンプトツールによる問い合わせ内容のカテゴライズ
- 他のエージェントへの接続 (マルチエージェント)
- エージェントの評価 (プレビュー)
- Microsoft 365 Copilot / Teams への公開と、環境のクリーンアップ
