# エージェントを公開する

作成したエージェントを公開し、Microsoft 365 Copilot から利用できるように構成します。

> [!IMPORTANT]
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。

1. エージェント デザイナーのツールバーの [Publish] の横にある ⌄ をクリックします。

2. [Publish agent] ダイアログで [Teams + Microsoft 365] を選択し、[Make agent available in Microsoft 365 Copilot] にチェックを入れます。

3. [Save and publish] をクリックします。

4. [See agent in Microsoft 365] をクリックします。

5. エージェントの追加ダイアログで [追加] をクリックします。

6. エージェントが追加されたら、質問を入力してテストします。

> [!NOTE]
>
> 他のユーザーが利用できるようにする場合は、エージェントのアクセス権や共有範囲の設定など、追加の設定や操作が必要です。
