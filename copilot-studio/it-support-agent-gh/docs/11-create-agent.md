# エージェントを作成する

この手順では、社内 IT に関する問い合わせに対応する IT サポート エージェントを作成します。

> [!IMPORTANT]
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。

## IT Support Agent を作成する

1. Copilot Studio にアクセスします。

   ```text
   https://copilotstudio.microsoft.com
   ```

> [!NOTE]
>
> この手順では、Copilot Studio の新しいエクスペリエンスを使用して、エージェントを作成します。
>
> クラシック エクスペリエンスが表示される場合は、ホームページで上部の **[今すぐ試す]** をクリックして切り替えてください。

2. 環境セレクターで、使用する Power Platform 環境を選択します。

3. 左側のナビゲーションから [Agents] を選択し、[New agent] をクリックします。

   または、[New agent] のドロップダウン メニューから [Agent] (Uses credits) をクリックします。

4. エージェント デザイナーのツールバーの [...] をクリックし、[Settings] をクリックします。

5. [Agent settings] ダイアログで、[Primary language] に [Japanese] を選択します。

6. [Agent settings] ダイアログを閉じます。

7. [Model] には [Claude Sonnet 4.6] を選択します。

8. エージェント名に以下を入力します。

   ```text
   IT Support Agent
   ```

### ナレッジを追加する

9. 右側のコンポーネント パネルの [Knowledge] で、[Search all websites] の右側に表示される [×] をクリックします。

   または、[Search all websites] をクリックし、[Add public websites] ダイアログで [Search all websites] をオフにします。
   
   これで、公開 Web サイトを参照させないようにします。

10. コンポーネント パネルの [Knowledge] で [+] をクリックします。

11. **[IT_FAQ.docx](../assets/IT_FAQ.docx)** ファイルをアップロードし、[Add to agent] をクリックします。

> [!NOTE]
>
> テストを実施する前に、[Knowledge] に追加した **IT_FAQ.docx** をクリックし、[Status] が **Ready** になっていることを確認してください。

### ツールを追加する

12. コンポーネント パネルの [Tools] で [+] をクリックします。

13. Support Ticket テーブルのレコードを作成および参照するために、Dataverse MCP Server を追加します。

    [ツールの追加] ダイアログで「Microsoft Dataverse MCP」を入力して検索し、[Microsoft Dataverse MCP Server] を選択します。

14. 接続のダイアログで既存の接続を選択するか、または [Create new connection] をクリックして接続を作成し、[追加] をクリックします。

15. [Tools] に追加した [Microsoft Dataverse MCP Server] をクリックします。

16. [Edit Microsoft Dataverse MCP Server] ダイアログで、ツール一覧の右上にあるトグルをオフにし、以下のツールのみをオンにします。

   - read_query
   - create_record
   - describe

17. [確認] をクリックします。

### スキルを追加する

18. コンポーネント パネルの [Skills] で [+] をクリックします。

19. [Add skill] ダイアログの [Upload a skill] タブで、以下のスキルをアップロードします。

    - [create-support-ticket.md](../assets/create-support-ticket.md)
      - サポートチケット作成時の対話および Dataverse への登録を行う

### インストラクションを設定する

20. [Instructions] に以下を入力します。

    ```text
    # 目的

    このエージェントは、社内 IT サポートに関する問い合わせに回答します。

    # 回答方針

    - 回答は必ず設定されたナレッジソースのみを使用して作成すること。
    - 一般知識、事前学習済み知識、Web 上の情報、推測を用いて回答してはいけない。
    - ナレッジソースに記載されていない内容を補完してはいけない。
    - ナレッジソースに十分な情報が存在しない場合は、分からないと回答すること。
    - 情報が不足している場合は、推測せずサポートチケット作成を案内すること。

    ---

    # サポートチケット作成

    ユーザーが以下を希望した場合は、サポートチケット作成の確認プロセスを開始してください。

    - サポートチケットを作成したい
    - 問い合わせを登録したい
    - サポートへ依頼したい
    - チケットを起票したい
    - IT 部門へエスカレーションしたい

    サポートチケット作成の確認プロセスで、問い合わせ内容についてユーザーから明示的な承認を取得した場合のみ、
    サポートチケット作成スキルを実行してください。

    問い合わせ内容の確認、サポートチケットの作成、および作成結果の案内は、スキルの手順に従ってください。

    ---

    # サポートチケット取得

    ユーザーがサポートチケットの確認を希望した場合は、現在のユーザーが作成したサポートチケットを取得して回答してください。

    検索条件が指定されている場合は、その条件も検索条件に含めてください。
    ```

21. エージェントを保存します。(右上の [保存] アイコンをクリックするか、`Ctrl` + `S` で保存します。)

## エージェントをテストする

上部の [Preview] タブを選択します。

> [!NOTE]
> 
> - エージェントの動きを詳細に確認する場合は、[End user preview] をオフにしてください。
> 
> - 会話のコンテキストをリセットする場合は、[New chat] をクリックします。

### テスト 1: ナレッジを利用した回答を確認する

1. チャット入力欄に以下のメッセージを入力して送信します。

   ```text
   PC から PDF ファイルを印刷したいのですが、なぜか印刷できません。プリンターの電源は入っています。
   ```

2. エージェントの回答内容を確認します。

   > 期待される動作:
   > - 社内 IT FAQ のナレッジに基づいた回答が生成されること

### テスト 2: サポート チケットを確認する

1. [New chat] をクリックして、新しいチャットを開始します。

2. チャット入力欄に以下のメッセージを入力して送信します。

   ```text
   Teams に組織外ユーザーを追加できません。エラーになります。
   ```

3. エージェントの応答を確認します。

   > 期待される動作:
   > - 問い合わせ内容に関する情報がナレッジにない旨の応答が返されること
   > - サポート チケットの作成が提案されること

4. エージェントの案内に従い、サポート チケット作成の対話を進めます。

   エージェントからのサポート チケット作成の提案に対し、「はい」または「作成してください」などと返答して同意します。

5. エージェントの応答を確認します。

   > 期待される動作:
   > - 問い合わせ内容が整理されて表示されること
   > - 作成予定のサポート チケット内容の確認が求められること

6. 表示された問い合わせ内容を確認し、「はい」または「作成してください」などと返答して同意します。

7. エージェントの応答を確認します。

   > 期待される動作:
   > - サポート チケットが作成された旨の応答が返されること
   > - チケット番号が表示されること
   
   > 内部動作:
   > - create-support-ticket-record スキルが実行されること
   > - Dataverse MCP Server のツールが呼び出されること
   > - Support Ticket テーブルにレコードが作成されること

> [!NOTE]
>
> Power Apps Maker Portal で Support Ticket テーブルを開き、先ほど作成されたサポート チケットのレコードを確認します。
>
> [その他の xx 件] をクリックして、表示する列を追加することができます。

### テスト 3: サポート チケットの状態を確認する

1. [New chat] をクリックして、新しいチャットを開始します。

2. チャット入力欄に以下のようなメッセージを入力して送信します。

   ```text
   オープン中のサポートチケットを列挙して
   ```

   ```text
   サポートチケット <チケット番号> の状態を教えて
   ```

3. エージェントの回答内容を確認します。

   > 期待される動作:
   > - オープン中のサポート チケット一覧を取得できること
   > - 指定したチケット番号の状態を取得できること

   > 内部動作:
   > - Dataverse MCP Server のツールが呼び出されること
