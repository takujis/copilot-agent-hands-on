# マルチエージェントを構成する

ここまでの手順で、社内 IT に関する問い合わせに対応する IT サポート エージェントを作成しました。

PC やスマートフォンなどの業務デバイスの貸出や返却に関する問い合わせも想定されますが、組織によっては、これらの業務デバイスの管理を別のチームが担い、IT サポートとは異なる業務領域として扱われる場合があります。

そこで、業務デバイスに関する問い合わせを担当する専用のエージェントを作成し、IT サポート エージェントから利用できるようにします。

> [!IMPORTANT]
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。

## Device Assistant エージェントを作成する

1. 左側のナビゲーションから [Agents] を選択し、[New agent] をクリックします。

2. エージェント デザイナーのツールバーにある [...] をクリックし、[Settings] をクリックします。

3. [Agent settings] ダイアログで、[Primary language] に [Japanese] を選択します。

4. [Agent settings] ダイアログを閉じます。

5. [Model] には [Claude Sonnet 4.6] を選択します。

6. エージェント名に以下を入力します。

   ```text
   Device Assistant
   ```
7. [Instructions] に以下を入力します。

   ```text
   # 目的

   このエージェントは、業務用デバイスおよび周辺機器に関する問い合わせに回答することを目的としています。

   # 対応範囲

   以下の問い合わせに対応します。

   - デバイスの返却
   - デバイスの交換
   - デバイスの貸出
   - デバイスの紛失
   - 周辺機器の貸出

   # 回答方針

   - 回答は必ず設定されたナレッジソースに基づいて作成すること。
   - 推測や一般的な知識に基づいて回答してはいけない。
   - ナレッジソースに記載されていない内容を補完してはいけない。
   - ナレッジソースに十分な情報が存在しない場合は、その旨をユーザーに伝えること。
   - ユーザーに回答を送信する前に、回答内容がナレッジソースに記載されていることを確認すること。
   - 確認できない情報は回答してはいけない。

   # 対象外

   以下の内容は、このエージェントの対応範囲外です。

   - 人事制度
   - 福利厚生
   - 経費精算
   - ライセンス申請
   - アカウント管理
   - アプリケーション障害
   - IT サポートチケットの作成
   - その他、業務用デバイスおよび周辺機器に関係しない内容

   対応範囲外の内容については回答せず、このエージェントの対応範囲外であることをユーザーに伝えること。
   ```

8. 右側のコンポーネント パネルの [Knowledge] で、[Search all websites] の右側に表示される [×] をクリックします。

   または、[Search all websites] をクリックし、[Add public websites] ダイアログで [Search all websites] をオフにします。
   
   これで、公開 Web サイトを参照させないようにします。

9. コンポーネント パネルの [Knowledge] で [+] をクリックします。

10. **[Device_Support_Guide.docx](../assets/Device_Support_Guide.docx)** ファイルをアップロードし、[Add to agent] をクリックします。

> [!NOTE]
>
> テストを実施する前に、[Knowledge] に追加した **Device_Support_Guide.docx** をクリックし、Status が **Ready** になっていることを確認してください。

11. 上部の [Preview] タブを選択し、チャット入力欄に以下のメッセージを入力して送信します。

    ```text
    デバイス交換のガイドラインを教えてください。
    ```

12. エージェントの回答内容を確認します。

13. Device Assistant をコネクテッドエージェントとして利用できるようにするため、エージェントを公開します。

    エージェント デザイナーのツールバーにある [Publish] をクリックします。

## IT Support Agent に Device Assistant を追加する

1. IT Support Agent を開き、[Build] タブを選択します。

2. コンポーネント パネルの [Connected agents] で [+] をクリックします。

3. [Add a connected agent] ダイアログで [Device Assistant] を選択します。

4. [Description] に以下を入力します。

    ```text
    業務用デバイスおよび周辺機器に関する問い合わせに回答するエージェントです。
    ```

5. [Connect] をクリックします。

6. [Instructions] の「サポートチケット作成」セクションの末尾に、以下を追加します。

   ```text
   ## サポートチケット作成の例外

   デバイスの返却、交換、貸出、紛失、および周辺機器の貸出に関する内容は、サポートチケットの対象外です。

   これらの内容については Device Assistant が対応します。
   ```

7. 続けて、[Instructions] の最後に以下を追加します。

    ```text
    # 業務用デバイスおよび周辺機器に関する問い合わせ

    ユーザーが以下に関する問い合わせを行った場合は、Device Assistant エージェントを呼び出してください。

    - デバイスの返却
    - デバイスの交換
    - デバイスの貸出
    - デバイスの紛失
    - 周辺機器の貸出・追加・交換

    例:

    - PC を返却したい
    - Surface が故障した
    - モニターを追加したい
    - ヘッドセットを借りたい
    - ノート PC を交換したい
    - 業務用 PC を紛失した

    これらの問い合わせについては、自身で回答せず、Device Assistant エージェントを呼び出してください。

    その際、以下のメッセージを表示してください。
    > デバイスに関する内容のため、Device Assistant が対応します...

    Device Assistant エージェントとメイン エージェントの応答を統合して回答する場合は、それぞれの役割や回答内容が分かるように整理して回答してください。
    異なるエージェントの回答内容を混同したり、結論を統合したりしてはいけません。​
    ```

8. エージェントを保存します。

## エージェントをテストする

1. IT Support Agent の [Preview] タブを選択します。

> [!NOTE]
> 
> - エージェントの動きを確認するため、テストを実施する際は [End user preview] をオフにしてください。
> 
> - 会話のコンテキストをリセットする場合は、[New chat] をクリックします。

2. チャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   ノート PC を返却したいです。どうしたらいいですか。
   ```

3. エージェントの回答内容を確認します。

   > 期待される動作:
   > - Device Assistant のナレッジに基づいた回答が生成されること

4. 会話のコンテキストをリセットするために、[New chat] をクリックします。
 
5. 次は、チャット入力欄に、以下のメッセージを入力して送信します。

   ```text
   PCが起動しません。何か対処方法はありますか？交換できるなら交換したいです。
   ```

6. エージェントの回答内容を確認します。

   > 期待される動作:
   > - ユーザーからの問い合わせ内容が、PC が起動できないことと、交換を希望していることに分解して理解されること
   > - 社内 IT FAQ および Device Assistant のナレッジに基づいた回答が生成されること

7. エージェントの回答をもとに、追加で質問を行ったり、サポート チケットを作成するなどして、会話を継続します。
