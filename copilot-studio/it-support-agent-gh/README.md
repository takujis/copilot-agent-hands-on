# IT サポート エージェント (Github copilot harness)

## 概要

このハンズオンでは、Microsoft Copilot Studio を使用して、架空の企業における社内 IT に関する問い合わせに対応するエージェントを作成します。

エージェントの作成を通じて、Microsoft Copilot Studio の基本的な操作方法や主要な機能について学習します。

> [!IMPORTANT]
>
> 本手順は IT サポート エージェントの設計や実装に関するベストプラクティスを示すものではありません。
>
> 社内 IT サポートを題材として、Microsoft Copilot Studio を利用したエージェント作成を体験し、主要な機能や操作方法を学習することを目的としています。

> [!IMPORTANT]
>
> 本ハンズオンでは、GitHub Copilot harness で動作するエージェントを作成します。
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。
>
> これは、エージェントの構築、テスト、評価、および実行に適用されます。
