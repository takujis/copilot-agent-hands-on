# 出張申請チェック エージェント (Standard harness)

## 概要

このハンズオンでは、Microsoft Copilot Studio を使用して、架空の企業における出張申請を社内規定に基づいてチェックするエージェントを作成します。

エージェントの作成を通じて、ファイル分析を実現する方法を学習します。

## 前提条件

- Microsoft Copilot Studio の試用版または有効なライセンス
- エージェントを作成する Power Platform 環境が準備されていること

> [!NOTE]
> 
> このハンズオンでは、エージェントの作成手順のみを説明しています。
>
> Power Platform 環境の作成やエージェントの公開などの手順については説明していません。
>
> 必要に応じて、[IT サポート エージェント](/it-support-agent/README.md) を参照してください。
