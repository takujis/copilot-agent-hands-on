# エージェントを作成する

この手順では、出張申請を社内規定に基づいてチェックするエージェント Travel Request Checker を作成します。

作成するエージェントは、出張申請の内容の不備や社内規定との不一致、費用見積りの問題点を確認し、申請者にフィードバックを提供します。なお、申請の承認や却下は行いません。

1. Copilot Studio にアクセスします。

   ```text
   https://copilotstudio.microsoft.com
   ```

2. 環境セレクターで、使用する Power Platform 環境を選択します。

3. 左側のナビゲーションから [エージェント] を選択し、エージェントを作成します。

   - 新しいエクスペリエンスの場合
     - [新しいエージェント] のドロップダウン メニューから [エージェント] (標準) をクリックします。

   - クラシック エクスペリエンスの場合
     - [空のエージェントを作成する] をクリックします。

> [!NOTE]
>
> 新しいエクスペリエンスからクラシック エクスペリエンスに切り替える場合は、ホームページで上部の **[New experience]** トグルをオフにします。
>
> クラシック エクスペリエンスから新しいエクスペリエンスに切り替える場合は、ホームページで上部の **[今すぐ試す]** をクリックします。

4. エージェントの名前と言語を設定し、[作成] をクリックします。

   | 項目 | 設定内容 |
   |------|------|
   | 名前 | Travel Request Checker (Standard) |
   | 言語 | 日本語 (日本) |

   [エージェント設定 (オプション)] を展開すると、言語の設定が表示されます。

5. 右上の [設定] をクリックします。

6. [生成 AI] > [オーケストレーション] で、[エージェントの応答に生成 AI オーケストレーションを使用しますか?] で [はい] が選択されていることを確認します。

7. [生成 AI] > [ナレッジ] で、[根拠のない応答を許可する] および [Webの情報を使用する] をオフにします。

8. [生成 AI] > [ファイルの処理能力] で、[ファイルをアップロードする] および [コード インタープリター] をオンにします。

9. 下部の [保存] をクリックして保存し、設定を閉じます。

10. エージェントの [説明] に以下を入力し、保存します。
   
    ```text
    出張申請書を分析し、経費見積の不備や社内規定との不一致の可能性をチェックするエージェントです。
    ```

11. エージェントのモデルとして [Claude Sonnet 4.6] を選択します。

12. [指示] に以下を入力し、保存します。

    ```text
    あなたは Travel Request Checker です。
    
    ユーザーがアップロードした出張申請書を確認し、申請内容の不備、経費見積の問題、社内規定との不一致の可能性をチェックしてください。
    
    あなたの役割は、出張申請書の内容を確認し、問題点や確認事項をユーザーに分かりやすく提示することです。申請の承認、却下、最終判断は行わないでください。
    
    以下の観点で確認してください。
    
    1. 出張申請書から基本情報を抽出する
    
    - 申請日
    - コストセンター
    - 社員番号
    - 氏名
    - 所属部門
    - 役職
    - 訪問国／訪問都市
    - 訪問先企業
    - 出張期間
    - 出張種別
    - 出張目的
    - 期待効果
    
    2. 経費見積を確認する
    
    - 経費項目、数量、単価、金額、備考を抽出する
    - 数量×単価と金額の整合性を確認する
    - 合計金額と明細合計の整合性を確認する
    - 未記入や不明な項目を確認する
    
    3. ナレッジに登録された社内規定に基づいて確認する
    
    - 必要事項の記載漏れ
    - 社内規定との不一致
    - 経費見積が社内規定に適合しているか
    - 確認が必要な事項
    
    4. 関連資料を確認する
    
    出張申請書とあわせて関連資料がアップロードされている場合は、内容の整合性を確認してください。
    
    関連資料の例:
    
    - イベント案内
    - 実施計画書
    - アジェンダ
    - その他関連ドキュメント
    
    ユーザーが関連資料とあわせてチェックしてほしい場合は、出張申請書と関連資料をまとめてアップロードするよう案内してください。
    
    出力形式:
    
    - 基本情報
    - 経費見積確認結果
    - 社内規定チェック結果
    - 関連資料確認結果
    - 総合的な確認事項
    
    注意事項:
    
    - ファイルおよびナレッジに記載された情報のみを使用する
    - 推測で情報を補完しない
    - 日付や数値は人が読める形式で表示し、Excel のシリアル値や内部値をそのまま出力しない
    - 判断できない場合は「不明」または「要確認」とする
    - 承認、却下、承認推奨などの判断は行わない
    ```

13. [ナレッジ] で [ナレッジの追加] をクリックします。

14. [**海外出張規定.docx**](../assets/海外出張規定.docx) ファイルをアップロードし、[エージェントに追加する] をクリックします。

> [!NOTE]
>
> テストを実施する前に、ナレッジに追加した **海外出張規定.docx** の状態が **準備完了** になっていることを確認してください。

## エージェントをテストする

作成した Travel Request Checker をテストし、エージェントの動作を確認します。

右上の [テスト] をクリックし、[エージェントをテストする] ペインを開きます。

サンプルの [**出張申請書**](../assets/海外出張申請書_sample.xlsx) と [**出張関連資料**](../assets/Asia_Leadership_Offsite_2026_案内_sample.docx) をダウンロードします。

## テスト 1: 出張申請書をチェックする

1. チャット入力欄に以下のメッセージと **出張申請書** ファイルを添付し、送信します。

    ```text
    出張申請書をチェックしてください
    ```

2. エージェントの回答内容を確認し、出張規定をもとに出張申請の内容がチェックされているかを確認します。

## テスト 2: 出張関連資料と合わせて出張申請書をチェックする

1. [+] をクリックして、新しいチャットを開始します。

2. チャット入力欄に以下のメッセージと **出張申請書** ファイルと **出張関連資料** ファイルを添付し、送信します。

    ```text
    出張申請書をチェックしてください
    ```

3. エージェントの回答内容を確認し、出張規定と出張関連資料をもとに出張申請の内容がチェックされているかを確認します。
